# 夢想藍圖

**手機正式網址**　[開啟夢想藍圖](https://xitian.page/dream/)

玄燁的護理與英文練習手帳。打開「今天」可以看到眼前的一件事，依今天的體力練一句。進度存在使用這個網址的瀏覽器裡。

## 手機第一次使用

1. 用手機常用的 Safari 或 Chrome 開啟上面的正式網址。
2. 在「今天」選電量，按開始，翻譯一個句子並自評。隔天再從同一個瀏覽器或已加入主畫面的 App 開啟。
3. 如果先前已在家中 Wi-Fi 預覽網址練過，從舊網址下載進度備份，再到正式網址的「設定」還原。

## 在電腦上預覽修改，用家裡的 Wi-Fi 試用

1. 在 Windows 電腦上開啟整個「夢想藍圖」資料夾。如果拿到的是 ZIP，先在檔案上按右鍵，選「全部解壓縮」。
2. 雙擊 **開啟夢想藍圖.cmd**。第一次會從網路下載開發工具，等電腦瀏覽器顯示首頁。若電腦尚未安裝 Node.js，下載 LTS 的 Windows Installer 安裝後，再雙擊啟動檔。[Node.js 官方下載](https://nodejs.org/en/download)
3. 讓手機和電腦連上同一個家用 Wi-Fi。把黑色視窗裡「手機網址」那一整串輸入手機瀏覽器。電腦自己開啟時使用 [本機預覽](http://localhost:4173/)。
4. 在手機按「今天」，選電量，開始練一句。完成後，用同一個手機瀏覽器和網址回來查看累計天數。練完可關閉視窗，下次再雙擊啟動檔。

預覽時保持電腦開機，保留啟動視窗。若 Windows 跳出防火牆詢問，請在自己信任的家用「私人網路」允許連線。若手機連不上，確認兩台裝置在同一個 Wi-Fi，請使用視窗裡顯示的 Wi-Fi／乙太網路網址。部分學校、醫院及訪客網路會隔離無線裝置。

## 安裝在手機、帶著離線練

手機透過同一 Wi-Fi 的 HTTP 網址可先練習。要使用離線快取及手機麥克風，請從 HTTPS 網站打開。電腦也可以透過上方的 localhost 網址體驗離線。[瀏覽器安裝條件](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable)

- **iPhone**　用 Safari 打開 HTTPS 網站，點「分享」→「加入主畫面」，有「打開為網頁 App」時將它開啟，再點「加入」。[Apple 操作說明](https://support.apple.com/zh-tw/guide/iphone/iphea86e5236/ios)
- **Android**　用 Chrome 打開 HTTPS 網站，在網址列右側選單點「安裝並建立捷徑」→「安裝」。[Google 操作說明](https://support.google.com/chrome/answer/9658361?co=GENIE.Platform%3DAndroid&hl=zh-Hant)

第一次請連網從主畫面開啟，等頁面及教材載入，重新開啟確認畫面正常，再切飛航模式試一題。朗讀無聲時可選「沒有聲音，改用看的」。錄音權限可略過。

**網站更新後**：開著的 App 或分頁會自己去看有沒有新版本（打開 15 秒後、切回來時、每 30 分鐘），下載好以後畫面最上面出現「新版本好了，點一下更新」，點一下就換成新版本，不用整個關掉。沒點的話，換到另一個頁面（例如從今日航行到英文練習），或離開 App 五分鐘以上再回來，也會自己換。寫到一半的句子和作文都有存草稿，不會不見。規則在 `public/register-sw.js`。

## 主選單：每一種練習自己一頁

每一種練習都有自己的一頁，一頁只放一種練習，不會把好幾種擠在同一頁（清單和順序寫在 `src/lib/library.ts` 的 `menuGroups`）。主選單「英文練習」底下依序是：

| 分組 | 裡面有（每一個都是自己一頁） |
| --- | --- |
| （不分組） | 中翻英、英文口說、句子跟讀、短文讀聽、閱讀理解、寫作階梯、單元讀聽說寫（到橋接單元才出現）、選擇題、文法講解、主題總複習（第一個主題上完才出現）、發音課 |
| 單字 | 單字複習、單字快篩、7000 單短文 |
| 護理英文 | 護理聽力、護理閱讀、護理單字、臨床情境；考週和實習期間護理英文題也在這裡 |

考週和實習期間不加新教材：寫作階梯、單元讀聽說寫、單字快篩先從選單拿掉，選擇題只剩護理英文題，改放在「護理英文」那一組。

- **電腦和平板**：左邊的主選單把上面每一種都列在「英文練習」底下（英文口說也在這裡），單字和護理英文前面有小標題。視窗比較矮、放不下的時候，只有這一串會自己捲動，「航行紀錄」「夢想星圖」一直看得到；還有沒露出來的項目時，那一端會淡出，提醒往下（或往上）捲。視窗高度不到 1000 的時候，左下角的目的地卡片會收起來讓出位置。
- **手機**：下面的「練習」打開「英文練習」這一頁：最上面是今天這一堂，下面是一列一列的練習清單（每列有一句說明，單字複習和中翻英會寫今天還有幾張／幾句要複習，主題總複習該考的時候會標「該考了」），點一列就進到那一種練習。「口說」在下面一排也還有自己的位置。
- 打開某一種練習後，左上角的「英文練習 ›」可以回到清單。上完每日課按「再多做一點」，也是回到這份清單挑一種。

每一種練習的網址都是 `#library/<種類>`（例如 `#library/sound`、`#library/story/listen`、`#library/writing/<題目>`），今天的清單和其他頁面就是用這些網址帶你過去；只開 `#library` 是清單本身。

### 英文程度測驗（起點測驗和每 12 週的回測）

程度測驗平常不出現在任何頁面。到了回測的日子（上次測驗後第 84 天；從來沒測過的裝置則是馬上），打開首頁、關掉今日單字之後會跳出一個小視窗：「開始測驗」或「今天先不要」。按了任何一個，當天就不再跳；沒做完的話隔天會再跳一次，做完就收起來，等下一個 12 週。到期的這段時間，「英文練習」清單最上面也會多一列「英文程度回測」，隨時可以進去。測驗本身和以前一樣（`src/components/Baseline.tsx`，網址 `#leveltest`），當天按掉的日期記在 `notes['baseline.later']`。

## Claude 批改照官方評分表

每一個「請 Claude 批改」都照官方公布的評分表給分（表在 `src/lib/rubrics.ts`，照官方說明整理成白話；每一頁都能打開「評分表」看全部級分和官方網址）。Claude 只能用表上的分數，理由要寫「符合第幾級的哪一句描述、為什麼沒有到高一級」，不可以用自己的標準，也不可以為了鼓勵給高分。分數不在表上、項目對不上，那一次就不算，再批一次。

| 哪裡 | 照哪一張表 | 分數 |
| --- | --- | --- |
| 中翻英、換個說法、單字造句 | 全民英檢初級寫作「單句寫作」 | 每句 0–2（2＝完全正確；1＝有錯，但這句要練的重點句型是對的；0＝錯太多或沒寫）。中翻英「對了」才是 2 分，「小錯」是 1 分，兩個不一致時照比較嚴的那個 |
| 寫作階梯 ① 一句完整的話、② 把句子寫長、③ 否定句和問句、④ 寫昨天的事、⑤ 連成一句 | 全民英檢初級「單句寫作」 | 題目要的每一句各 0–2，總分七成以上算過（初級寫作 70 分通過）；不另加整段的檢查項 |
| 寫作階梯 ⑥ 三到五句的小短文、⑦ 一段、⑧ 說出意見和理由；每日課「用自己的話寫」、生活主題的寫作和重述 | 全民英檢初級「段落寫作」 | 0–5 級分；寫作階梯 4 級分以上算過 |
| 寫作階梯 ⑨ 多段、⑩ 描述數字和變化、⑫ 兩面意見的短文、⑭ 橋接段落 | 全民英檢中級「英文作文」 | 0–5 級分，4 級分以上算過（中級 80 分通過） |
| 寫作階梯 ⑪ 雅思 Task 1、⑬ 雅思 Task 2 | IELTS Writing Band Descriptors（官方公開版，2023 年 5 月） | 四項各給整數 band；這一題的分數＝四項平均，照雅思的方式進位（.25 進到 .5、.75 進到下一個整數），5.5 以上算過 |
| 7000 單短文 | 全民英檢中級「中譯英」 | 0–5 級分 |
| 生活主題的口說情境（說完打下來的文字）、全民英檢口說練習 | 全民英檢初級／中級口說 | 0–5 參考分；聽不到聲音，只評內容、文法和字彙，不是官方分數 |

寫作階梯的批改會列出每一個分數、那一級在表上的意思和 Claude 的理由，再加上這一階自己的要求（主題句、連接詞、這一課的文法……）有沒有做到。其他批改框的判定跟著分數走：最高一級才是「全對」，低一級是「小錯」，更低是「要再練」（意思跟題目不一樣另外標「意思不一樣」），所以不會有錯卻說全對。

寫作階梯共有 **14 階、每階 100 題，合計 1,400 題**，從「I am a student.」這樣的完整短句開始，先學把一句話寫對，再慢慢加長、接成段落和文章。原有 59 題的題目、範文和 ID 全部保留，這次新增 1,341 題；舊作答、分數和草稿仍對應原來那一題。

| 階段 | 練什麼 | 題數 |
| --- | --- | --- |
| ① 一句完整的話 | 我是誰、家人做什麼，先寫主詞和動詞；每題三句，至少 10 字 | 100 |
| ② 把句子寫長 | 加大小、地點、時間和頻率；每題三句，至少 15 字 | 100 |
| ③ 否定句和問句 | 不做什麼、是不是、做不做、在哪裡；每題三句，至少 15 字 | 100 |
| ④ 寫昨天的事 | 昨天做了、沒做什麼，練過去式；每題三句，至少 20 字 | 100 |
| ⑤ 連成一句 | 用 and／but／so／because 說明關係和原因 | 100 |
| ⑥ 三到五句的小短文 | 按 First、Then、After that、Finally 寫日常或練習流程 | 100 |
| ⑦ 一段 | 一句主題、三個支持細節、一句結論 | 100 |
| ⑧ 說出意見和理由 | 說清楚看法，給兩個理由和一個實際例子 | 100 |
| ⑨ 多段 | 寫訊息、email、經驗和小文章，分清開頭、內容、結尾 | 100 |
| ⑩ 描述數字和變化 | 看小圖表，比較上升、下降、持平、最高與最低 | 100 |
| ⑪ 雅思 Task 1 | 先寫總覽，再挑關鍵數據比較，至少 150 字 | 100 |
| ⑫ 兩面意見的短文 | 開頭、兩邊理由、結論，先用四段練論述 | 100 |
| ⑬ 雅思 Task 2 | 討論兩方、問題與解決、優缺點、同意程度，至少 250 字 | 100 |
| ⑭ 橋接段落 | 配合單元 48–53 的時態、推測、假設、願望和關係子句 | 100 |

手機上的階段列可以左右滑，開啟時會帶到目前這一階。題目每次列出 10 題，用「上一組／下一組」或「選題範圍」直接找題號；打開單元給的題目時也會帶到正確那一組。橋接題依單元分組、各自編號，未上到的單元照樣鎖住。每階通過 2 題即可往下一階，100 題是留給反覆練習的題庫，不必一次全部寫完。

新題由日常、家人、學校和宿舍逐步增加護理學習、實習溝通與赴美準備情境；同一情境也會練不同寫作目的，例如平常的流程、昨天的經驗、遇到問題後的調整。新增圖表都標明是教學模擬資料，範文依題目數據寫出變化與比較，不把虛構數字當成真實醫療統計。

**每一階的題目上方都有「這一階要用的文法」**：白話重點、中英例句和常見錯誤，例句旁的喇叭可以聽，速度照設定。這一階沒做過時先展開，做過後先收起，點標題隨時能重看。批改時 Claude 也會收到該階教過的文法，不因沒用尚未教的更難句型另扣分；分數仍只照官方評分表，不降低雅思的要求。

新增的護理情境已查核官方來源：宿舍洗手依 [CDC 一般洗手五步驟](https://www.cdc.gov/clean-hands/about/)（搓洗至少 20 秒，不把它寫成全程只需 20 秒）；醫療洗手的區別可對照 [WHO 洗手海報](https://www.who.int/docs/default-source/patient-safety/how-to-handwash-poster.pdf)（全程 40–60 秒）。血壓練習依 [美國心臟協會的量測說明](https://www.heart.org/en/health-topics/high-blood-pressure/understanding-blood-pressure-readings/monitoring-your-blood-pressure-at-home)，保留安靜休息、正確姿勢、壓脈帶與手臂位置等重點。這些是英文寫作情境，臨床操作仍依學校與實習單位的完整流程。

病人身分確認依 [Joint Commission 的兩項識別資訊說明](https://www.jointcommission.org/en-us/knowledge-library/support-center/standards-interpretation/standards-faqs/000001463)，用姓名和出生日期核對，不把床號或手圈本身當識別資訊；手機情境依 [NCSBN 社群媒體與病人隱私指引](https://www.ncsbn.org/public-files/NCSBN_SocialMedia.pdf)，不以私人手機拍攝病人，工作用途依實習單位規定使用核准工具。

連接 Claude 之後，練習頁不放參考答案：中翻英按「請 Claude 批改」就直接送出，沒有「看參考句」；換個說法沒有「看答案」；寫作階梯沒有「看參考範文」。卡住就問 Claude，或寫過一次之後按「直接告訴我」（算有提示完成）。只有 Claude 連不上（沒網路、額度用完、金鑰錯）時，參考句、看答案和參考範文才會回來；沒連 Claude 的裝置照舊自己對答案。

官方說明：[全民英檢初級（寫作／口說能力測驗分數說明）](https://www.gept.org.tw/exam_intro/t01_introduction.asp)、[全民英檢中級](https://www.gept.org.tw/exam_intro/t02_introduction.asp)、[IELTS Writing Band Descriptors](https://ielts.org/cdn/ielts-downloadable-assets/ielts-guidance-and-support/ielts-guides/ielts-writing-band-descriptors.pdf)。

## 前一級達成，下一級才打開

有分級、分階段或照順序上的練習，前面那一級沒達成，後面的都鎖著（規則在 `src/lib/unlock.ts`，各頁的條件寫在各自的 lib）。鎖住的那一格是灰的，上面直接寫要達成什麼才會打開；鎖住只是不能點，已經做過的紀錄都還在。

| 練習 | 怎麼算達成，下一級才打開 |
| --- | --- |
| 閱讀理解、護理閱讀 | A1 簡單 → 中等 → 難 → A2 簡單 → 中等 → 難 → B1 簡單 → 中等 → 難 → B2 簡單 → 中等 → 難：前一小級過關八成才開下一小級（12 篇要 10 篇、10 篇要 8 篇、8 篇要 7 篇）；五篇以下維持要三篇，不足三篇就全部過關。過關＝沒看中文、答對七成以上。沒有文章的小級不擋後面；讀過的小級和它前面，以及更新前已打開的級別，都不會鎖回去 |
| 寫作階梯 | ① 一句完整的話 → ② 把句子寫長 → ③ 否定句和問句 → ④ 寫昨天的事 → ⑤ 連成一句 → ⑥ 三到五句的小短文 → ⑦ 一段 → ⑧ 說出意見和理由 → ⑨ 多段 → ⑩ 描述數字和變化 → ⑪ 雅思 Task 1 → ⑫ 兩面意見的短文 → ⑬ 雅思 Task 2：前一階有 2 題照評分表過關才開下一階。做過的階段和它前面的階段保持打開；更新前已解鎖的也保留，建議不會倒退到新增的前面幾階。⑭ 橋接段落上到第一個橋接單元（現在是單元 48）才開，裡面每個單元的題目上到那個單元才開 |
| 短文讀聽 | 六個級別，讀、聽、聽寫各算各的：這一級這一種做完八成，才開下一級 |
| 7000 單短文 | 六個級別：這一級完成八成才開下一級 |
| 護理聽力 | 基礎 A2 → 中級 B1 → 中高級 B2：這一級只聽（不看字）答對七成以上的對話達到八成，才開下一級；鎖住那一級的對話不會出現，清單上是灰的 |
| 發音課 | 照順序：前一堂過關才開下一堂 |
| 文法講解 | 課程上到的單元才打開，後面的單元等上到再看 |
| 主題總複習 | 一個主題最後一個單元上完才打開；還沒上完的主題在「換一個主題」裡鎖著 |
| 單元讀聽說寫 | 上到那個單元才打開那一包（不能先預習） |
| 全民英檢口說練習 | 初級的「回答問題」拿到 4 級分（官方通過的級分）才開中級 |

存起來的級別如果被鎖住（例如在別台裝置選過），會自動退回最高一個打開的級別。

寫作階梯更新時會一次記住舊版已解鎖的位置（`migrate.writing-ladder-14`），不修改任何 `write.<題目 id>` 作答紀錄。舊版已完成兩題「句子」的人，「一段」仍然打開；新開始的人則照 13 階主線逐階進行。這次各階擴充到 100 題不提高升階門檻，也不新增進度遷移；已開的階段不會因題庫變多而鎖回去。橋接段落獨立跟著單元走，不會變成主階梯的建議。

## 今日單字

每天第一次打開首頁會先跳出一張正方形的「今日單字」卡片，依字表順序，每 56 個單字配一輪天文實拍照。翻看中文或播放發音時，照片保持固定。單字來自 7000 單（大考中心高中英文參考詞彙表，六級共 6,012 個詞條），從第 1 級開始。先想意思，再看中文，按「認得」或「還不熟」；還不熟的字隔天進複習。預設每天 20 個，卡片最後或「設定 → 我的學習節奏」可改成 5、8、10、15、20、25 或 30 個。考週和實習期間預設只排 1 個，想多看可以自己加。關掉之後，首頁的「今日單字」按鈕可以再打開。卡片下方的「上一個／下一個」可以往回看今天按過的字（記在 `daily-word.sorted.<日期>`），會直接顯示中文和當時按的是認得還是還不熟，按錯可以改：改成還不熟就變成明天的複習卡，改成認得就把今天新開的卡拿掉，今天看過的個數不變。官方把星期、月份、數字、國名放在字表附錄，不在六級裡，所以今日單字不會出，每日課會教。

### 單字卡上的發音和「跟 Emma 聊這個字」

單字旁邊的「問問 Claude」只顯示那隻紫色小寵物（跟右下角「問問 Claude」按鈕上的同一隻），按了一樣打開 Claude 聊這個字；只有直接拿單字當按鈕的地方（例如閱讀理解「文章裡不懂的字」）才保留文字。

「單字複習」的複習卡在英文旁邊有喇叭，按了念一次（照設定的語速）。每張卡下面有「跟 Emma 聊這個字」：打開 Emma 的語音聊天，她知道你在哪一份清單（單字複習或護理單字）、在練哪一種（看懂、聽懂、說出、寫出）、卡片上是哪個字，還有這一輪接下來的幾個字。她會先說你在複習這個字，再找你用它說句子；想問意思、用法或這一輪的其他字，直接問她。看懂的複習卡還沒翻中文的話，她會先讓你猜意思；聽懂、說出、寫出的卡要先作答才會出現這顆按鈕，免得先看到答案。聊天上面有「回到單字複習」。這些資訊都放在網址裡（`#speaking/word-…`，規則在 `src/lib/wordChat.ts`），重新整理也不會不見。

### 複習卡怎麼排

規則都在 `src/lib/progress.ts`（`intervals`、`reviewBudget`、`reviewLoad`），今日清單、今日單字和兩個複習畫面都讀同一份，數字不會對不起來。

- **排程用 FSRS-6**（open-spaced-repetition 的預設參數）：每張卡記著「穩定度」（隔幾天還有九成機會想起來）和「難度」。自己想起來，穩定度往上長（剛學的字大約 2 → 6 → 17 → 44 → 102 → 220 → 365 天）；想不起來或看了答案，穩定度縮小，但不會從頭來；中翻英小錯算「勉強想起來」，升得比較慢；自評的對了沒人確認就原地不動。最長 365 天。新卡當成「那天還不會」開始；舊版的卡第一次複習時，用它原本的間隔當起點。「紀錄」頁的格子只是看卡片現在隔幾天。
- **單字卡**在「單字複習」：一天的上限照時間算，五張一分鐘：一般日 100 張（20 分鐘），考週和實習 50 張。超過上限的照到期順序排到明天。
- **句子卡**在「中翻英」：每日課寫過的句子，和從 Emma、短文、課堂存下來的錯句。一句大約一分鐘，一天排 5 句；多的照到期順序排到之後的日子，想多做可以繼續。
- 今日清單的「複習卡」寫出今天要做幾張單字卡、幾句句子卡，兩個按鈕各自帶到單字複習和中翻英；單字複習做完，還有句子卡的話也會提醒去中翻英。
- **新字跟著複習量調整**（`newWordPlan`）：超過今天上限、今天複習不完的單字卡積 30 張以上開始減、80 張先暫停；照 FSRS 的到期日，接下來一週每天平均要複習的單字卡超過一天上限的八成，新字減到 10 個（超過上限減到 5 個）；最近兩週單字複習只記得不到 75%（至少 30 次），新字減半。卡片和今日清單會寫出原因。今天清得完的卡、排在後面的句子卡都不會擋新字。
- 複習多的日子，清單上的複習時間最多多 10 分鐘，從加練、今日單字（最少 5 分鐘）、說或寫（最少 15 分鐘）依序挪，一天的總時數不變。
- **7000 單照計畫的速度**（每天打開今日單字、看 20 個新字、先做複習，週日也開）：第 1 級約 2027 年 1 月、第 2 級約 2027 年 3 月（趕在全民英檢初級之前）、第 3 級約 2027 年 7 月、第 4 級約 2027 年 12 月看完（趕在 2028 年 2 月實習和全民英檢中級之前）；實習和國考那段每天只排 1 個新字，第 5 級約 2029 年 6 月、第 6 級約 2029 年 10 月。這是用上面的規則一天一天推算的（第 1 級約四成不認得，越後面越多；改了規則用 `npm run words:pace` 重算，`WORDS=8 npm run words:pace` 可以看別的個數），複習一天平均約 18 分鐘、最多約 28 分鐘；週日沒開會晚 1–7 個月，第 4 級會拖進實習期間（約 2028 年 7 月）。原本預設每天 8 個時，第 4 級要到 2029 年 8 月才看完，比它要對應的全民英檢中級（2028 年初）晚一年半，所以改成 20 個。

## 7000 單短文

「英文練習」底下「單字」那一組有「7000 單短文」：六級共 1,476 段日常生活的中文短文，照級別和字母順序排，每一段都是圍繞該字母的單字寫的。先自己翻成英文，按「請 Claude 批改」：Claude 照全民英檢中級「中譯英」的官方評分表給 0–5 級分（5 級分才是全對，4 級分是小錯），先一次給一個提示讓他自己改，改好再批；判「全對」或「小錯」才出現「完成，下一段」，要再練的可以按「今天先到這裡，明天再來這段」。卡住或想問某個字怎麼說，按「問問 Claude」，會帶著這段短文和目前寫到的內容打開聊天。畫面上沒有參考翻譯、自評和複製按鈕；只有這台裝置沒連 Claude、或 Claude 連不上時，才出現「先自己對答案」（參考翻譯＋自評）。六級 1,476 段都有參考翻譯（給 Claude 判斷用），盡量用到該字母的詞條；「這段會用到的單字」列出這段的單字。每個單字提示都指到這段英文裡真的出現的字（例如 saw 會標成 see 的過去式「看見」），中文是這一句裡的意思，不是字表最常見的意思；文章沒用到的字不列。寫法不只一種，意思和文法對就算對。

## 短文讀聽（閱讀、聽力、聽寫）

「英文練習」的「短文讀聽」把同一批 1,476 段 7000 單短文的英文（六級共約 5.8 萬字）拿來當輸入練習，規則在 `src/lib/story.ts`，畫面在 `src/components/StoryLibrary.tsx`，紀錄存在 `story.<短文 id>`：

| 分頁 | 怎麼練 | 怎麼算 |
| --- | --- | --- |
| 閱讀 | 一句一行，每個字都能點：先給這一段自己的意思（短文的單字提示），沒有就查 7000 單字表，變化形會找回原形（walked → walk、took → take）。每句可以單獨播放。 | 按「讀完了」考最多 3 個沒查過的提示字（這段裡的意思，三選一），再出現整段中文。先看了中文就不考。讀完記一天「讀」。查過的字可以一次加進單字複習。 |
| 聽力 | 先不看字整段播完，自己選聽懂多少（幾乎都懂／大概懂／聽不太懂），再打開文字一句一句跟讀、看中文。 | 整段播到最後才算一天「聽」；裝置沒有聲音或沒回報播完時可以看字，但不算聽力。 |
| 聽寫 | 一次播一句，寫下聽到的，再對答案：寫對幾個字、多寫的字畫波浪線、沒寫到的字列出來。大小寫、標點、縮寫不算錯。 | 寫完兩句以上可以收工；整段的正確字數存起來，算一天「聽」。 |

- **順序**：中翻英從每一級的第一段往後做；讀聽先出已經翻譯過的段落，其他的從最後一段往前，所以還沒翻譯的段落不會先被看到英文。聽寫先出讀過或聽過的段落。
- **今天的清單**：「聽或讀」的「聽」連到短文聽力（原本的句子跟讀還在「英文練習」和寒假的聽力那一格）；「讀」先連到有題目的閱讀理解，A1–B1 的 105 篇（A1 39 篇、A2 36 篇、B1 30 篇）都讀過以後改連短文閱讀（`QUESTION_PASSAGES`，改了篇數測試會提醒）。
- 聲音是裝置的電腦語音，不是真人錄音；速度用設定裡的朗讀速度。
- **有題目的閱讀理解**（`src/data/reading.json`）：共 147 篇，包含 129 篇一般文章與原有 18 篇單元橋接文章。橋接裡的 6 篇回測仍只在單元回測出現，所以一般閱讀頁的總數是 141 篇。A1 39 篇、A2 36 篇、B1 30 篇、B2 一般文章 24 篇；另外 18 篇橋接也屬 B2，但不拿來湊 B2 各小級至少 8 篇的一般文章。內容從學校、家人、宿舍、公車與便條，逐步加入實習、衛教、教育、科技、環境與健康政策。

選級分兩排：第一排 A1／A2／B1／B2 顯示整級過關篇數，第二排簡單／中等／難顯示各小級篇數與「建議」。鎖住的按鈕直接寫前一小級需要過關幾篇、目前幾篇；篇數門檻用 `levelTarget`，一小級一小級開放。單元讀聽說寫的 `only` 模式只看那包文章，不顯示兩排選級，也不受小級篩選影響。

紀錄仍在 `read.<文章 id>`，原題順序、選項、答案和解析不動，新題只接在 `qs` 後面。舊作答的 `picks` 比現在題數短時，`readSummary` 跳過尚未作答的新題，不把它們算錯；過關仍依當次保存的分母與最佳成績判斷。已讀過的小級會保留它和前面的小級，之後仍能接著升級；「建議」則從最簡單、還沒過關的小級開始（舊版已經打開的整級除外），一步一步往上，開著的小級隨時可以自己點。舊版已開放的整級，依原有題庫和舊成績保留，不因擴充題庫提高門檻。新作答加上選填的 `bandVersion`，重做時保留舊的 `legacyBest` 作為已取得權限的依據；不更換儲存鍵、不清除進度，也不需要改寫舊備份。`tests/reading.test.ts` 另保存本次更新前原文與原題的雜湊作回歸檢查，防止補題時改到以前的作答位置。

閱讀教材的醫療內容已對照官方資料：洗手的搓洗時間與順序依 [CDC 洗手說明](https://www.cdc.gov/clean-hands/about/)；量血壓前安靜休息、姿勢、裸露上臂及不說話依 [CDC 量血壓說明](https://www.cdc.gov/high-blood-pressure/measure/)；就醫前準備問題與藥物資訊依 [MedlinePlus 就醫溝通](https://medlineplus.gov/ency/patientinstructions/000860.htm)；請病人用自己的話說明、發現不清楚就再解釋依 [AHRQ teach-back 指引](https://www.ahrq.gov/health-literacy/improve/precautions/tool5.html)。防跌、傷口變化、醫療口譯與健康資訊判讀等新文也以官方衛教資料查證；虛構的課堂、醫院與政策案例只作英文閱讀練習，不把案例中的數據寫成真實研究結果。

B2 的抗生素文章另核對 [CDC 抗生素使用說明](https://www.cdc.gov/antibiotic-use/about/)；知情同意的課堂案例明確以 [NHS 同意治療說明](https://www.nhs.uk/tests-and-treatments/consent-to-treatment/) 為參考，限於有決策能力成人的溝通例子；病人入口網站的文件範圍、更正途徑與下載隱私核對 [NHS App 文件說明](https://www.nhs.uk/nhs-app/help/documents/)。

## 文法講解和小練習

每個單元除了原本的一段規則，另外有一份講解（`src/data/grammar.json`，53 個單元都有；規則在 `src/lib/grammar.ts`，畫面在 `src/components/GrammarTeach.tsx`）：

- **三步講解**：每一步一個重點、白話說明和兩個例句（可以點來聽）。
- **一張對照表**：例如主詞配哪個 be 動詞、不規則動詞、三類假設。
- **兩個常見錯誤**：錯的句子、對的句子和原因。
- **七題小練習**：選擇 3 題、填空 2 題、改錯 2 題。填空和改錯用打的，大小寫、標點、縮寫（isn't = is not）不影響；改錯題從錯的句子開始改，沒改不能交。答完出現完整的正確句子和原因。

上課時，「句型」那一步先出講解和小練習，再寫中翻英：單元第 1 天完整講解加前 4 題，第 2 天再 2 題，第 3 天最後 1 題；之前答錯的題目之後每天會先出現，直到答對。小練習不擋住中翻英，也不算進「我會什麼」的證據（那裡只看自己寫出來的句子）；紀錄存在 `gram.<單元>`，只記第一次的對錯，後來改對的另外標記。小關卡（第 6 天）不出講解。

「英文練習」的「文法講解」可以翻課程上到的任何一個單元的講解、把七題從頭再做一次（還沒上到的單元鎖著；`#library/grammar/<單元>` 直接打開那個單元）。新增或修改單元時，`tests/grammar.test.ts` 會檢查每題只有一個標準答案、改錯題的原句不會被判對。

### 主題總複習（一個主題學完，混在一起考）

好幾個單元連著教同一種文法時（例如單元 7–10 都是過去式，連上四週），最後一個單元的小關卡過了以後，接下來的休息日首頁會出現「主題總複習」：把整個主題混在一起考一次，還把以前學過、同一類的文法一起混進來（過去式就混進現在式和現在進行式），練的是分辨「什麼時候用哪一個」。規則在 `src/lib/themes.ts`，畫面在 `src/components/ThemeReview.tsx`。

- **哪些單元算一個主題**：53 個單元各屬於一個主題（`themes`），同一類的主題（例如時態類：現在式、進行式、過去式、完成式…）彼此算相關。連著兩個以上單元是同一個主題，才有總複習：名詞和冠詞（2–3）、現在式（4–5）、過去式（7–10）、連接詞（21–22）、完成式（36–37）、對比和因果（39–40）、子句（42–43）、假設語氣（51–52）。
- **考什麼**：第一部分是文法題，從那幾課自己的小練習裡出（教過才考），主題裡每一課 3–5 題（選擇、填空、改錯盡量各一題），以前學過的相關文法每課 1 題、最近學的那一課 2 題，總共十幾題，全部打散，答完才告訴你是哪一課。課堂上錯過的題目、上次總複習錯的題目先出。第二部分是 2 句中翻英：一句是主題最後一課的備用句，一句是以前學過、另一個主題的句子；上面不標文法，要自己判斷，有 Claude 就照全民英檢單句寫作評分表批改。
- **什麼時候出現**：課表走過那一段主題、還沒考過，就算「該考了」。首頁只在休息日（和沒排課的日子）出現，考週和實習期間不出現；英文練習清單上的「主題總複習」會標「該考了」，隨時都能做。只提醒最近的那一個主題：上一個沒考、又上完下一個主題，就換成新的那一個（舊的還是可以在「換一個主題」裡考）。
- **怎麼算**：答對八成算這個主題穩了；結果依單元列出來，有錯的單元旁邊有「看講解」，直接打開那個單元的文法講解。錯的題目記進「我的弱點」（來源寫「複習」），也記進那一課的小練習紀錄（只記第一次的對錯，跟課堂一樣）。中翻英的兩句跟其他地方的中翻英一樣判定、一樣排進句子複習卡。
- **存在哪裡**：`theme.<主題代號>`（例如 `theme.past-7`）：最近一次的成績、錯的單元和題目、兩句的判定，加上第一次考的成績（再考一次不會蓋掉第一次）。

## 發音課（女聲、男聲示範）

「英文練習」的「發音課」有 17 堂短課，照順序上（前一堂過關才打開下一堂），每堂 5–8 分鐘，專門教中文母語者最容易念錯、聽錯的地方（內容在 `src/data/pronunciation.json`，規則在 `src/lib/pronunciation.ts`，畫面在 `src/components/Pronunciation.tsx`）：

| 堂 | 內容 |
| --- | --- |
| 1 | KK 音標表：29 個符號各配一個字，點了就聽 |
| 2–6 | 母音對比：sheep／ship、bed／bad、luck／lock、pool／pull、pain／pen |
| 7–10 | 子音：咬舌音 think／sink、l／r／n、v／w、字尾子音 back／bag |
| 11 | -ed 和 -s 的三種念法 |
| 12–13 | 單字重音、句子的輕重（can／can't、13／30） |
| 14–15 | 連音、問句的語調 |
| 16–17 | 長單字拆開念：生活常用字 16 個（beautiful、comfortable、university…）、護理常用字 16 個（emergency、thermometer、antibiotic…） |

**長單字拆開念（第 16、17 堂）。** 每個字切成音節，每一段標 KK 音標，重音那一段用大寫、顏色標出來。點一小段聽那一段；「一段一段念，再合起來」照順序念每一段、慢速的整個字、正常速度的整個字；「慢慢加長」是第一段、前兩段、前三段……一路加到整個字；正在念的那幾段會亮起來。測驗問重音在哪一段。小段不是單獨錄的，是從同一段慢速錄音切出來的（做法和限制見 `scripts/pronunciation/README.md` 的「長單字切音節」），所以聽起來像字的一部分；沒下載到聲音包時只能聽整個字。

每一堂四步：

1. **怎麼念**：嘴型、舌頭位置，和中文裡最接近的音；一格「容易錯的地方」。
2. **聽聽看**：每個字點一下就播，「比一比」把一組對比字連著念。預設女聲、男聲各念一次（同一個字聽不同的人念，耳朵才認得），也可以只聽其中一個；另外可以切慢速（七成速度，音高不變）。
3. **聽辨小測驗**：只用耳朵選。對比字問「聽到的是哪一個」，字尾問念 [t]、[d] 還是 [ɪd]，重音問在哪一個音節，連音和語調是寫好的題目。選「兩個都聽」時女聲、男聲輪流出題。答對八成算過關，可以重測，紀錄留最好的一次（`pron.<堂>`）。
4. **跟著念**：三個句子，聽完自己念出聲再打勾，可以錄下來跟示範比（錄音只留在畫面上，不會上傳也不會存）。三句都勾了，當天的「說」就算一天。

今天清單的「說或寫」在發音課還沒全部過關之前，會先指到下一堂發音課（不需要任何金鑰）；17 堂都過關後回到 Emma。

**聲音怎麼來的。** 示範不是真人，也不是裝置內建的語音：每個字、每個句子都用開源語音模型 Kokoro-82M（Apache-2.0）預先合成女聲和男聲各一份，放在 `public/pron/`，一堂一個聲音一包（`p01-f.pack`、`p01-m.pack`，共 34 包約 10.5 MB，全部約 15 分鐘的聲音；最後兩堂的切音節佔了一半）。女聲主要是 af_bella、男聲主要是 am_adam，個別的字換成同性別的另一個聲音。合成時給的是音標而不是拼字，重音和母音照音標念；每一段錄好後再用語音辨識檢查：單字要在「只差一個音的字」和它的對比字裡明顯勝出，句子要一字不差地被聽回來，而且是壓成 mp3 之後、量三次都過才算；沒過的換速度或換同性別的另一個聲音重錄。對比字一開始準備得比課程裡多，女聲、男聲都念得清楚的才留下（例如男聲的 seat 聽起來像 seed，所以 seat／sit 沒有放進課程；cup／cop 女聲分不清楚，換成 luck／lock）。打包好的成品再整個檢查一次。製作工具和每一段的檢查紀錄在 `scripts/pronunciation/`。

語調那一堂另外處理：這個語音模型幾乎每一句的句尾都往下掉，連 yes／no 問句也一樣。該下降的句子用原本合成的版本；該上升的句子，句尾的音高是後製拉上去的（重新合成），做完再量一次音高確認方向。

發音包不跟著 App 一起下載：打開一堂課時才抓那一堂的兩包，抓過的會留在裝置裡（離線可播，App 更新也不會清掉）；課程清單最下面可以一次全部存好。抓不到的時候（第一次打開又剛好沒網路）會改用裝置的語音念，畫面上會寫明。

發音課能教的是「聽得出差別」和「知道怎麼念」。App 聽不到你的聲音，不會評你的發音；要有人聽你念，還是要找老師或同學。

## 弱點清單、口說回饋、英檢口說

- **我的弱點**（`src/lib/weakPoints.ts`，設定 →「我的弱點」）：Claude 批改中翻英和寫作、自己對答案按小錯或不會、文法小練習答錯、跟 Emma 聊完和英檢口說練習的回饋，都會把錯記成一個弱點，名稱用課程的 53 個文法名稱（或用字、拼字、字序、漏字或多字、意思跑掉）。同一種錯越多次越前面，三週沒再錯減半，之後同一種文法自己寫對一次扣一次。Claude 老師、Emma、問問 Claude 和交給其他 AI 的交接文字都會看最前面 5 項。記錯的可以刪掉。
- **Emma 知道學到哪**：一般聊天也會帶最近學過的單元、正在學的、還沒學的和最近的弱點。學過的文法說錯先給提示讓他自己改，還沒學的直接說一次對的（雅思 Part 2 不糾正）。
- **聊完的固定回饋**：這次的文法說對幾次、最多 3 句修正（自動加進複習，語音辨識聽錯的可以移除）、下次可以用的一句（可以聽）、一句鼓勵。
- **全民英檢口說練習**（口說頁 →「練全民英檢口說」）：初級（複誦、朗讀句子與短文、回答問題）和中級（初級的回答問題拿到 4 級分才打開；朗讀短文、回答問題 10 題 15／30 秒、看圖敘述 30 秒＋1 分 30 秒）各三回。朗讀和複誦只比對語音辨識聽出哪些字；回答問題和看圖敘述由 Claude 看逐字稿給「內容和語言」的參考分，清楚標示不是官方分數。看圖敘述有三張畫好的圖，也可以用自己的照片（Claude 出提示問題）。語音辨識用 OpenAI `gpt-transcribe`（沒有就退回 `gpt-4o-mini-transcribe`），沒有 OpenAI 金鑰時用瀏覽器內建的。
- **朗讀比對**：發音課的句子、每日課的聽說練習和英檢朗讀，都可以念一次看哪些字沒被聽出來（不是發音分數）。
- **先教再用**：`tests/taught.test.ts` 檢查所有要他自己寫的句子（每日課、換個說法、文法小練習、生活主題）沒有用到還沒教、旁邊也沒教的文法，5–6 級和字表外的字也一定先當過新字。

## 宇宙圖鑑與背景

「宇宙圖鑑」收錄 56 張天文觀測影像，分為星雲 12 張、星系 12 張、太陽系 12 張、恆星與星團 10 張，以及深空 10 張。點分類，再點影像即可放大。每次切換主要頁面或重新開啟 App，滿版背景就接續輪替。在自動輪替下，56 張全看過後才重複。頁首搭配另一張實拍照，閱讀、答題和切換同頁設定時，照片保持固定。想固定某頁的全頁背景時，在大圖底下的「頁面背景」選頁面，按「設為這張」。按「自動輪替」能恢復該頁輪替。

每張照片的出處、署名與授權記錄保存在影像資料檔，建置時一併輸出為[影像出版資訊](https://xitian.page/dream/publication.html)。App 的 HTML 文件標頭透過 `rel="license"` 指向這份清單。照片來自 NASA、ESA/Hubble 與 ESA/Webb 的官方圖庫。引用或轉載時，請保留該張完整署名，並查看原始頁面的使用條款。[NASA 科學影像](https://science.nasa.gov/) · [ESA/Hubble 影像庫](https://esahubble.org/images/) · [ESA/Webb 影像庫](https://esawebb.org/images/)

如果要在沒有網路的地方瀏覽全部照片，請先用正式網址打開「宇宙圖鑑」，按「保存全圖庫供離線瀏覽」，等到顯示「全庫可離線瀏覽」。56 張 WebP 合計約 8.3 MB。下載中斷時可連線再按一次，已保存的影像會保留。新手機還原進度後，請在新手機上重新保存圖庫。

## 把進度帶到其他裝置

1. 在原裝置開「設定」→「備份與還原」→「下載備份」，保留下載的 JSON 檔。換網址、換瀏覽器或清除網站資料前，也先做一次。
2. 在新裝置開「設定」→「備份與還原」→「選擇備份檔」，選取 JSON 後按「確認還原」。匯入會取代目前的進度，有想保留的資料時可先下載備份。
3. 到「紀錄」核對累計天數，再回首頁看英文單元位置。

資料儲存在目前裝置。手機與電腦各有自己的進度；從預覽網址換到正式網址時，用備份把進度帶過去。

也可以在「設定」→「雲端硬碟」接上自己的 Google Apps Script，讓進度和記住的事同步到自己的試算表：

- 每台裝置記得自己上次同步時雲端那一份的時間。雲端比這個時間新、這台也改過，就是**衝突**：不會自動互蓋，設定頁會讓你選留這台還是留雲端那份。
- 新版腳本（設定頁的程式碼，v2 起）在伺服器端也會檢查這個時間，兩台同時存檔時只有一台成功。還沒換新版腳本時，網頁這邊會先檢查一次，但同時按存檔的極短時間內仍可能互蓋，所以請照設定頁的步驟更新並重新部署。
- **歷史版本（v3）**：雲端的進度要被蓋掉前，腳本先把舊的那份存進雲端硬碟的「夢想藍圖・歷史版本」資料夾（最多每小時一份；選版本、還原時一定留），留最新 30 份。設定 → 她記得的事 → 雲端硬碟 →「雲端歷史版本」可以還原任一份，還原前的進度也會先存進去，可以反悔。第一次換成 v3 要在 Apps Script 執行一次 `setupHistory` 允許存取雲端硬碟，再部署新版本。`tests/cloudScript.test.ts` 用模擬的 Google 服務跑過這份腳本。
- **舊紀錄封存（v4）**：手機的瀏覽器大約只能存 5 MB，所以手機只留最近的紀錄。兩個月以前的複習紀錄、幾週前的每天小紀錄（今天的單字、今天的勾選）、四個月前上完的課的批改全文，連著雲端硬碟時會先存進「夢想藍圖・封存」資料夾（大約一週一份檔案，永遠不會被刪），雲端回覆收到了，手機才拿掉那幾筆；紀錄頁的總數和每週比賽的加分照舊。腳本還沒換成 v4 時，舊紀錄會先留在手機等，超過 3.5 MB 才會不等直接整理。沒連雲端硬碟的裝置直接整理（複習紀錄變成統計數字，自己寫的句子都留著）。
- 刪掉的記憶會記在「已刪除的記憶」，別台的舊資料合併回來時不會復活。
- 對話逐字稿寫進試算表預設是**關閉**的，要在設定頁自己打開。

## 教材與個人資料

英文課表原本以玄燁提供的 42 單元順序為準。2026-11-24 拿英國文化協會與 EAQUALS 的 Core Inventory for General English（A1–B2 各級文法清單）和 Basic Grammar in Use 重新對照：補上 5 個單元（限定詞、附和和問句、介系詞進階、比較和程度、動詞句型），並把每一級要會的文法排在報名那一級證照之前（例如現在完成式、過去進行式、動名詞、if 條件句改到初級之前，過去完成式、第二類假設、although、because of 改到中級之前）。現在是 47 個主線單元，再接 6 個 B1→B2 橋接單元（48–53），共 53 個單元，每個都有完整的每日教材：第 1–5 天每天三句中翻英（今天的句子，再加兩句同句型的「換個說法」，一個單元十句不重複，`lessons.json` 的 `variations`，第 d 天用第 2d−1、2d 句），表達題也一天一題（`prompts`，五題）；第 6 天三句小關卡，另有 5 句沒過關時用的備用句。`tests/lesson.test.ts` 會檢查十句換個說法不重複、也不和這單元的每日句、小關卡、備用句撞在一起。考週、實習與休息都能暫停；每天以裝置當地凌晨 4 點換日。

### 英文程度階梯（A1 → C2）

課程照 CEFR 分級往上排，每一級最後考一張證照，考過才算升級（`src/lib/cefr.ts`，畫面在「夢想星圖 → 英文程度」）：

| 這一段 | 每日課 | 7000 單 | 結業證照 | 預估 |
| --- | --- | --- | --- | --- |
| A1 → A2 | 單元 1–28 | 第 1–2 級（照計畫約 2027/3 看完） | 全民英檢初級（聽讀＋說寫） | 2027 年下半年（單元 7 月下旬上完） |
| A2 → B1 | 單元 29–40 | 第 3–4 級（第 3 級約 2027/7、第 4 級約 2027/12，實習之前） | 全民英檢中級 | 2028 年初（單元 10 月下旬上完） |
| B1 → B2 | 單元 41–47，再接橋接單元 48–53 | 第 5–6 級（約 2029/10） | 全民英檢中高級，或雅思學術組 5.5 以上 | 2030 年中 |
| B2 → C1 | 還在寫，先用雅思閱讀、寫作、口說練 | 學術字彙 | 雅思 7.0（或全民英檢高級） | 2031 年底 |
| C1 → C2 | 選修，不排進五年計畫 | | 雅思 8.5 或劍橋 C2 | 到美國以後 |

- **關卡怎麼擋**：下一段的每日課，要等前一段的證照考過、或至少報名了（填上考試日期）才開。等成績的時候可以先讀；成績沒過，就要再報名下一場才會接著上。日曆也照這個規則排：已經上到下一段的第一天還沒報名，日曆就停在那裡；關卡還在後面的時候，日曆照計畫當作上完就報名，不會先把後面幾個月都排成複習。53 個單元上完以後沒有下一段的課要開，所以不會擋（B2→C1 的每日課還沒寫）；中高級照計畫等 7000 單第 5–6 級看完（約 2029 年 10 月，國考後）再報名，「英文程度」和日曆上單元 53 那天都會這樣寫（`cefr.ts` 的 `bookWhen`）。
- **全民英檢**要聽讀和說寫兩個都過，可以分開考（及格線：聽讀合計 160、單項不低於 72；說寫初級寫作 70、口說 80，中級以上都 80）。直接考過更高一級也算（沒考初級、直接考過中級就是 B1）。也可以填其他證照和它的 CEFR 等級。
- **美國 RN 的 VisaScreen** 要雅思學術組總分 6.5、口說 7（2026-05-12 之後考的）。填了雅思成績，達到就會顯示，並提醒成績一般兩年內要送件。VisaScreen 不收全民英檢，所以 C1 那關要考雅思。
- 費用、場次和及格線是 2026 年 11 月查的，寫在 `cefr.ts` 的 `exams`；改了就改那裡。
- **Emma 不冷場**：GPT-Live 邊聽邊說，什麼時候開口、什麼時候停是模型自己決定的，沒有設定可以調，所以靠三件事（`emmaPrompt.ts`、`voiceTurns.ts`、`voice.ts`）：
  1. 指示照 OpenAI 的寫法分成 Language／Taking turns／Backchannel policy／Interruption policy：她帶話題、每次說完整一句再問一題、不只回「Oh」；他六秒沒回就換簡單的問法或給句子開頭；雜音和喇叭傳回來的自己的聲音不算被打斷。
  2. 開場用 `session.input` 的 developer 訊息叫她先開口；兩邊都安靜 10 秒，app 用 `session.instructions.append` 提醒她說話（他沒回應最多連續兩次）。服務不收這兩樣時，通話照常，只是少了它們。
  3. **防回音**（語音設定裡，預設開）：她出聲時麥克風先關掉，停 0.45 秒再打開，喇叭的聲音就不會讓她以為被打斷；一次最多關 15 秒。戴耳機想插話可以關掉。雅思 Part 2 不用防回音也不催他。
- **Emma 的程度跟著每日課走**：A1→A2 那段她講很簡單、很慢的 A1–A2；A2→B1 是 A2–B1；B1→B2 換成正常語速、一次兩三句，會追問 why／how；B2→C1 再加上抽象話題，要他說理由、比較和推測（`cefr.ts` 的 `emmaLevel`）。

### 課表只有一份

整份英文課表只有一個來源：`src/lib/projection.ts` 的 `planDays()`。它從 `src/data/curriculumSchedule.json` 的 `start`（2026-11-24，第一堂課）開始，用和日曆一模一樣的規則一天一天往後排：預設的上課日（週一到週六）每天一堂，生活主題和文法課輪流；考週、寒暑假、實習和國考期用 `periods`；每一級的單元上完就當作已經報名那一級的證照。照這樣排：

| 什麼時候 | 上到哪裡 |
| --- | --- |
| 2026-11-24 | 單元 1 第 1 天 |
| 2027 年 7 月下旬 | 單元 28 上完（A1→A2）→ 報名全民英檢初級 |
| 2027 年 10 月下旬 | 單元 40 上完（A2→B1）→ 報名全民英檢中級 |
| 2028 年 1 月 20 日 | 單元 53 上完；中高級等 7000 單第 5–6 級看完（約 2029 年 10 月）再報名 |
| 2028-02 至 2029-07 | 實習、國考衝刺：只做護理英文 |
| 2029 年 8 月起 | 每天 1.5 小時：7000 單第 6 級、中高級，接著雅思（B2→C1） |

用到這份計畫的三個地方：

- **計畫 → 每月行程**：點一天，下面的「原課表安排」就是 `planDays()` 那一天的安排；格子本身是照自己最近四週的進度重排的。還沒走到的升級關卡，日曆和計畫一樣當作上完就報名；已經上到關卡還沒報名，日曆才停在「升級關卡」。
- **月計畫**（`src/data/plan.json` 的 `months`，2026-11 到 2033-12 每個月一筆）：英文那一行寫的「每日課單元 a–b」、生活主題和要報名的證照，都要和 `planDays()` 那個月一樣。學校、夢想線可以留空（例如國考衝刺那幾個月的夢想線），留空的那一格不會出現在目標裡。
- **年度目標**（`plan.json` 的 `years`）：每一年寫的每日課單元也要一樣。

`tests/plan.test.ts` 會一個月一個月比對，對不上就失敗。改了上課日、時期、生活主題或單元數，先跑 `npm test`，照失敗訊息改月計畫的文字。

### B1→B2 橋接單元（43–48）

接在單元 47 後面、考中高級之前（現在是單元 48–53），補 B2 常用但前面沒教的句型：敘事時態（過去進行、過去完成、used to）、未來進行和未來完成、推測（must／might／can't have）、第三類假設、wish 和 should have、加逗號的非限定關係子句。每個單元照樣一週六天，第 6 天是小關卡，沒過一樣用備用句再練，不拆成兩週。

每個橋接單元另外有一包讀聽說寫（`src/data/bridge.json`，畫面在「英文練習 → 單元讀聽說寫」）：

| 一包裡有什麼 | 怎麼做 |
| --- | --- |
| 詞塊 15–20 個 | 先聽例句跟著念；可以遮住英文，看中文先說再對答案。 |
| 閱讀兩篇（B2，約 250–320 字） | 用閱讀理解原本的作答方式；文章就用這一課的文法寫。 |
| 聽力一段 | 電腦語音，盡量用英式或澳洲口音（看裝置有沒有那種語音，沒有就用其他英文語音，畫面上會寫）。先不看字聽完才開題目，播放沒確認聽完的不算「只聽也懂」。這不是真人錄音。 |
| 寫作兩題（約 100、120 字） | 每單元保留原有兩個指定題，放在寫作階梯的「⑭ 橋接段落」；該階另有各單元的加練，總共 100 題。照全民英檢中級「英文作文」給 0–5 級分，第一個要求是有沒有用到、用對這一課的文法。每題仍上到對應單元才開，不增加每日指定量，也不會變成主階梯的建議。 |
| 口說兩個任務 | 跟 Emma 練（`#speaking/pack-單元-題號`），她會照任務演情境、追問，句型錯了請他再說一次。 |
| 回測 | 一篇沒看過的閱讀和一段沒聽過的聽力（換一種口音），第 6 天或上完單元才開，各只有一次機會、只記第一次。回測的文章不會出現在閱讀理解裡。成績會和練習文章並排，看學的東西能不能用在新的材料上。 |

今天的清單也會用到：「聽或讀」「說或寫」會看這週聽、讀、說、寫各做了幾天，指向做得少的那一個（一樣多時先聽、先說）；目前的單元有讀聽說寫包時直接連進去，第 6 天的「聽或讀」換成回測。

每天多久由 `src/lib/dailyPlan.ts` 一處決定，首頁的三個選項、今天的清單、待辦那一行和計畫日曆都讀它，所以分鐘數不會各說各話：

| 哪一天 | 預設 | 其他選項 |
| --- | --- | --- |
| 學期中週一到週六（設定裡的上課日） | 1.5 小時：複習 15、一堂 30、單字 10、聽或讀 20、說或寫 15（卡片多的日子複習最多 25，單字和說或寫各讓 5 分鐘） | 有電 2 小時（加練 30）；累爆 15 分鐘（複習＋單字） |
| 寒假週一到週六 | 3 小時：複習 20、一堂 30、單字 20、聽力跟讀 25、閱讀 25、寫作 20、口說 20、證照準備 20 | 有電 4 小時（加練 60）；累爆 30 分鐘 |

| 週日、過年、沒排課的日子 | 15 分鐘複習，標「選做」 | 想上課也可以選 |
| 段考週 | 15 分鐘複習或休息，標「選做」 | 30 分鐘護理英文 |
| 實習（2028-02 起） | 20–30 分鐘護理英文：複習、聽或讀一段護理英文，再輪流練護理單字／跟 Emma 演一段／護理題 | 忙的日子 10 分鐘 |
| 國考衝刺（考試期間連續四週以上） | 15 分鐘護理英文 | 忙的日子 5 分鐘 |

### 今天的清單怎麼打勾

- **複習卡**：今天沒有到期的卡就直接算完成（第一天會寫「還沒有複習卡，先跳過」），旁邊的按鈕改成選做的單字快篩。
- **今天這一堂**：引導課要做到最後一步「表達」才打勾；單元小關卡（第 6 天）做完也算，而且同一天不會再排生活主題（`mainLessonDone`、`courseMovedOn`）。
- **上課中回頭看**：引導課從「句型」開始，右上角有「上一步」，步驟列上已經做過的「聽懂」「句型」也可以直接點。回頭看只是重看（對話和逐字稿、文法講解和今天寫的句子），不會重新計分；原本那一步只是先收起來，寫到一半的字和小練習的進度都還在，按「回到…」就接著做。
- **換個說法也能請 Claude 老師批改**：換個說法每天兩句，畫面上寫「換個說法 1／2」「2／2」，寫完第一句才出第二句（中途離開，下次從還沒寫的那句接著）。連接 Claude 之後，這兩句和主要的句子一樣有「請 Claude 批改」（照單句寫作 0–2 分）：先提示錯在哪、不直接給答案，改好可以再批一次。Claude 說對了，或寫過一次後按「直接告訴我」，參考句和評分按鈕才會打開；連接 Claude 時沒有「看答案」，Claude 連不上才會出現。記錄的標準和其他句子相同：第一次就對是當次獨立完成，被指出問題後改好或老師給了答案是有提示完成。沒有連接 Claude 時照舊，自己對照參考句。
- **聽或讀**：要真的去聽或讀才算（短文讀聽、閱讀理解、「英文練習」的句子跟讀、單元聽力）。課堂裡跟讀的那一句屬於那堂課，不算。
- **說或寫**：發音課的三個句子跟著念完、跟 Emma 說過話，或在寫作階梯存了一題。
- **先補強**：做了它要求的練習就會自己勾（聽懂練習當天答對 5 個字，或在「英文練習」的中翻英多寫 2 句）。
- 每一項左邊的方框都可以自己勾或取消。

首頁在第一次練習之前會有一張「第一次用？照這三步就好」的說明卡，上完第一堂課或按「知道了」就不再出現。

寒假文法課還是一天一堂：關卡是證照，不是單元數，上太快只會記不住，多出來的時間全部拿去聽讀說寫和準備下一張證照。清單裡每一項的分鐘加起來就是選項上寫的分鐘；今天有「先補強」時，從複習時間裡撥出來。舊的預設（週二、四、六各 30 分鐘）會自動換成週一到週六；自己改過的上課日不動。

2028 年 2 月至 2029 年 7 月是實習和國考，暫停新單元，7000 單的今日單字一天只出 1 個，其他時間做護理英文（見下方「護理英文」）。假期有排實習時用實習模式，只有沒有實習的假期才啟用寒暑假模式。

學籍與待修科目取自 2026-11-13 提供的資料。每週正式上課節次、部分計畫明細在附件中留白，可在設定更新。基護已確認安排在暑假，年份與日期尚未指定。畢業年月以校方確認為準。2033–2034 年是玄燁期望抵美的時間，實際日期取決於畢業、考試與當時的移民排期。跨國執照、簽證等規定請用地圖列出的官方連結再次查閱。

## 生活主題

生活主題放在 `src/data/topics.json`，接在每日主線裡，和文法課輪流上（上一個練習日是生活主題，下一個就是文法課；同一天只排一堂）。前四個（認識新同學、一天的作息、房間與住處、點餐與買食物）在上完單元 1、5、6、7 後依序開放；後面五個補文法單元沒有獨立教到的文法，一樣照順序開放（重排之後跟著原本的單元走）：

| 主題 | 上完單元幾開放 | 補的文法 |
| --- | --- | --- |
| 5 這是誰的？ | 8 | me／my／mine／myself（受格、所有格、所有格代名詞、反身代名詞，by myself） |
| 6 照著說明做 | 15 | 形容詞和副詞（slow／slowly、good／well、hard／hardly；look、feel 接形容詞） |
| 7 這也太好吃了吧！ | 21 | so 和 such、so／such … that …（和單元 21 的 so「所以」對照） |
| 8 確認一下，對吧？ | 29 | 附加問句（…, isn't it?／…, do you?，助動詞跟著前面的時態，語調和回答） |
| 9 請人幫你處理 | 30 | 使役句 have／get something done（接在單元 30 被動語態的過去分詞後面） |

主題的 id 接著編（t5–t9），既有單元、題目和單字的 id 都沒有動，學過的進度不受影響。每個主題分三次：

1. 理解：單字在句子裡選意思 → 句型中翻英 → 聽（只聽大意 → 再聽細節 → 看逐字稿 → 跟讀 → 重述）→ 讀（主旨、細節、指涉、文章有沒有提供）。只聽、不看字時的答案先存起來，重聽次數和看逐字稿另外記。
2. 說和寫：只給情境和要做到的條件。口說可以錄音（只留在畫面上），把說的話打下來或轉成文字再請 Claude 看；只看文字稿，所以發音一律記「未評估」，並給一到兩個下次的目標。訊息寫 3–5 句。
3. 換情境：第 2 次之後至少隔 3 天，三句新句子加一個新的口說情境。有兩句以上自己寫、而且確認過，才記成「延後換題仍能完成」。

判定和其他地方一樣：沒寫是未作答；看過提示或參考是有提示完成；沒人確認的自評是自評完成・待確認；Claude 第一次就說對、或跟參考答案一樣，才是當次獨立完成。句子會進複習卡，字典裡有的新單字會進單字卡。想先上文法課，按「今天先上文法課」就好，生活主題下次接著做。

聽力只算**整段播完**的那次；裝置沒回報播放結束時可以按「播完了，但題目沒有打開？」先作答，但那次不算「只聽就懂」。口說分成「錄了音」「說了但沒錄」「用打的」三種，用打的不算口說。寫作訊息要 3–5 句（兩個字以上才算一句）。計畫日曆用同一套規則排出生活主題的日子。

## 維護與更新

1. 下載或複製 `body` 專案後，進到 `projects/dream-blueprint/`。Windows 可直接雙擊「開啟夢想藍圖.cmd」。已在本機練習的人，可沿用同一瀏覽器、網址與埠號讀取原有進度。
2. 在上述原始專案目錄開啟終端機。使用 Node.js 24 與 npm，在乾淨副本中逐行執行以下指令。

```powershell
npm.cmd ci
npm.cmd test
npm.cmd run build
npm.cmd run check:offline
```

3. 本機預覽請執行 `npm.cmd run preview -- --host 0.0.0.0 --port 4173`。在手機依前文的步驟測試，包含完成一句、關閉重開，以及還原進度備份。
4. 將建置產生的 `dist/` 內容同步至同一份 `body` 專案根目錄下的 `dream/`，核對網站檔案清單並移除該目錄過時的舊雜湊檔。確認發佈目錄中有 `index.html`、`sw.js`、`manifest.webmanifest`、`assets/` 與 `cosmos/` 的 56 張影像。將原始專案變更及對應的網站檔案放進同一個 Git 提交，檢查差異只出現在 `projects/dream-blueprint/` 與 `dream/`。
5. GitHub Pages 完成發布後，用手機進入本文開頭的正式網址。連網開啟一次，等背景更新後關閉重開。先核對原有累計天數與課表進度，再切飛航模式試練一句。

正式網址下的瀏覽器儲存會跨版本保留，App 開啟時會將舊資料轉成目前格式。修改教材時請維持既有題目、單元與單字 ID。改了已上線教材的意思或答案時，把改到的單字和句子 ID 加進 `src/data/content-updates.json`：使用者學過的那幾張卡會排進當天複習，進度不歸零，首頁會出現一次「教材修正了」。

字表（`levels.json`）的 `zh` 用「；」分開不同意思，`sensePos` 依序標出每個意思的詞性；合併詞條（he (him, his, himself)、agree(ment)）的 `forms` 列出每個字形自己的意思，拼字練習一次只問一個字形。短文的單字提示（`passages.json` 的 `words`）是照每一段的句子寫的，`form` 是文章裡的字、`zh` 是那一句的意思；修改字表時不要拿字表的中文覆蓋短文提示。

作答判定在每個入口都一樣：沒寫答案不算作答；看過提示或答案是「有提示完成」；自己按「對了」但沒有可核對的答案是「自評完成・待確認」；答案和參考答案一致或 Claude 第一次批改就判對，才是「當次獨立完成」；之後換一句還能獨立寫對，才會變成「穩了」。

幾個細節：Claude 的「對了」只算它看過的那一版，看完再改句子就要重新確認（只差標點不算改）；第一次被指出錯、改完才對，是有提示完成；學生寫的縮寫（He's、I'd）兩種讀法都會試，參考句的縮寫照後面的字決定是 is／has、would／had；重音字母（café）不算錯。自評的「對了」不會讓複習卡升級，只是先停在原地，確認過才往上升。單字「說出」目前沒有錄音核對，記成「說出（自評）」；「聽懂」要等聲音真的播出來才能選。寫作批改的分數要在評分表上（全民英檢 0–5 的整數級分、單句寫作每句 0–2、雅思每項整數 band），項目也要對得上，不然整筆不算；雅思這一題的 band 由四項平均照雅思方式進位算出來，不用 Claude 自己寫的；Task 2 依題型（討論兩方、問題＋解決、同意程度）給不同的結構提示。閱讀同一天重做是練習，不會蓋掉第一次的成績。修改資料格式時請補上遷移與匯入測試，保留舊備份可讀性。更新照片時請在同一筆影像資料保留署名與官方頁面，並重新建置影像清單。
