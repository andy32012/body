# 夢想藍圖

**手機正式網址**　[開啟夢想藍圖](https://xitian.page/dream/)

玄燁的護理與英文練習手帳。打開「今天」可以看到眼前的一件事，依今天的體力練一句。進度存在使用這個網址的瀏覽器裡。

## 手機第一次使用

1. 用手機常用的 Safari 或 Chrome 開啟上面的正式網址。
2. 在「今天」選電量，按開始，翻譯一個句子並自評。隔天再從同一個瀏覽器或已加入主畫面的 App 開啟。
3. 如果先前已在家中 Wi-Fi 預覽網址練過，從舊網址下載進度備份，再到正式網址的「設定」還原。

## 在電腦上預覽修改，用家裡的 Wi-Fi 試用

1. 在 Windows 電腦上開啟整個「夢想藍圖」資料夾。如果拿到的是 ZIP，先在檔案上按右鍵，選「全部解壓縮」。
2. 雙擊 **開啟夢想藍圖.cmd**。第一次會從網路下載開發工具，等電腦瀏覽器顯示首頁。若電腦尚未安裝 Node.js，下載 LTS 的 Windows Installer 安裝後，再雙擊啟動檔。[Node.js 官方下載](https://nodejs.org/en/download)
3. 讓手機和電腦連上同一個家用 Wi-Fi。把黑色視窗裡「手機網址」那一整串輸入手機瀏覽器。電腦自己開啟時使用 [本機預覽](http://localhost:4173/)。
4. 在手機按「今天」，選電量，開始練一句。完成後，用同一個手機瀏覽器和網址回來查看累計天數。練完可關閉視窗，下次再雙擊啟動檔。

預覽時保持電腦開機，保留啟動視窗。若 Windows 跳出防火牆詢問，請在自己信任的家用「私人網路」允許連線。若手機連不上，確認兩台裝置在同一個 Wi-Fi，請使用視窗裡顯示的 Wi-Fi／乙太網路網址。部分學校、醫院及訪客網路會隔離無線裝置。

## 安裝在手機、帶著離線練

手機透過同一 Wi-Fi 的 HTTP 網址可先練習。要使用離線快取及手機麥克風，請從 HTTPS 網站打開。電腦也可以透過上方的 localhost 網址體驗離線。[瀏覽器安裝條件](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable)

- **iPhone**　用 Safari 打開 HTTPS 網站，點「分享」→「加入主畫面」，有「打開為網頁 App」時將它開啟，再點「加入」。[Apple 操作說明](https://support.apple.com/zh-tw/guide/iphone/iphea86e5236/ios)
- **Android**　用 Chrome 打開 HTTPS 網站，在網址列右側選單點「安裝並建立捷徑」→「安裝」。[Google 操作說明](https://support.google.com/chrome/answer/9658361?co=GENIE.Platform%3DAndroid&hl=zh-Hant)

第一次請連網從主畫面開啟，等頁面及教材載入，重新開啟確認畫面正常，再切飛航模式試一題。朗讀無聲時可選「沒有聲音，改用看的」。錄音權限可略過。

## 今日單字

每天第一次打開首頁會先跳出一張正方形的「今日單字」卡片，依字表順序，每 56 個單字配一輪天文實拍照。翻看中文或播放發音時，照片保持固定。單字來自 7000 單（大考中心高中英文參考詞彙表，六級共 6,012 個詞條），從第 1 級開始。先想意思，再看中文，按「認得」或「還不熟」；還不熟的字隔天進複習。預設每天 8 個，卡片最後可改成 5、8、10 或 15 個。考週和實習期間預設只排 1 個，想多看可以自己加。關掉之後，首頁的「今日單字」按鈕可以再打開。

## 宇宙圖鑑與背景

「宇宙圖鑑」收錄 56 張天文觀測影像，分為星雲 12 張、星系 12 張、太陽系 12 張、恆星與星團 10 張，以及深空 10 張。點分類，再點影像即可放大。每次切換主要頁面或重新開啟 App，滿版背景就接續輪替。在自動輪替下，56 張全看過後才重複。頁首搭配另一張實拍照，閱讀、答題和切換同頁設定時，照片保持固定。想固定某頁的全頁背景時，在大圖底下的「頁面背景」選頁面，按「設為這張」。按「自動輪替」能恢復該頁輪替。

每張照片的出處、署名與授權記錄保存在影像資料檔，建置時一併輸出為[影像出版資訊](https://xitian.page/dream/publication.html)。App 的 HTML 文件標頭透過 `rel="license"` 指向這份清單。照片來自 NASA、ESA/Hubble 與 ESA/Webb 的官方圖庫。引用或轉載時，請保留該張完整署名，並查看原始頁面的使用條款。[NASA 科學影像](https://science.nasa.gov/) · [ESA/Hubble 影像庫](https://esahubble.org/images/) · [ESA/Webb 影像庫](https://esawebb.org/images/)

如果要在沒有網路的地方瀏覽全部照片，請先用正式網址打開「宇宙圖鑑」，按「保存全圖庫供離線瀏覽」，等到顯示「全庫可離線瀏覽」。56 張 WebP 合計約 8.3 MB。下載中斷時可連線再按一次，已保存的影像會保留。新手機還原進度後，請在新手機上重新保存圖庫。

## 把進度帶到其他裝置

1. 在原裝置開「設定」→「備份與還原」→「下載備份」，保留下載的 JSON 檔。換網址、換瀏覽器或清除網站資料前，也先做一次。
2. 在新裝置開「設定」→「備份與還原」→「選擇備份檔」，選取 JSON 後按「確認還原」。匯入會取代目前的進度，有想保留的資料時可先下載備份。
3. 到「紀錄」核對累計天數，再回首頁看英文單元位置。

資料儲存在目前裝置。手機與電腦各有自己的進度；從預覽網址換到正式網址時，用備份把進度帶過去。

## 各階段怎麼體驗

| 階段 | 開啟後可以做什麼 | 還要補什麼 |
| --- | --- | --- |
| 1．先練一句 | 「今天」選電量，翻一句、看提示、自評，隔天用同一個網址接著練。設定可下載備份。 | 單元 8–42 的句子若有不自然的地方，按「這題怪怪的」記下來再修。 |
| 2．把學校的事接起來 | 在地圖看已確認的基護暑假安排，到設定可編輯學校資料。想競賽時看對手，考週或實習改成休戰。 | 暑假年份與詳細日期以後可在設定補上。 |
| 3．看長期方向 | 從「計畫」看月曆、每年三條線與八站地圖；從「紀錄」看自己的練習累積。 | 開學後依實際工作量重排，畢業與赴美時程依實際進度更新。 |
| 4．把它帶到手機 | 從本文開頭的正式網址進入，加入主畫面並離線練習。 | 首次需連網下載教材。 |

每月小測、擴充題庫與經人工逐題審查的臨床情境題留在後續版本。

## 教材與個人資料

英文課表以玄燁提供的 42 單元順序為準。42 個單元都有完整的每日教材：每單元 5 天各一句中翻英、第 6 天三句小關卡，另有 5 句沒過關時用的備用句。考週、實習與休息都能暫停；每天以裝置當地凌晨 4 點換日。兩分鐘能保住練習習慣，英文檢定仍需要長時間練習。

2028 年 2 月至 2029 年 7 月是英文維持期，預設每天用 2 分鐘複習學過的內容，暫停新單元與 7000 單。2029 年 2–7 月預排國考衝刺，使用考週模式。假期有排實習時用實習模式，只有沒有實習的假期才啟用寒暑假模式。

學籍與待修科目取自 2026-11-13 提供的資料。每週正式上課節次、部分計畫明細在附件中留白，可在設定更新。基護已確認安排在暑假，年份與日期尚未指定。畢業年月以校方確認為準。2033–2034 年是玄燁期望抵美的時間，實際日期取決於畢業、考試與當時的移民排期。跨國執照、簽證等規定請用地圖列出的官方連結再次查閱。

## GitHub 專案與網站

同一個 GitHub 專案保存兩個目錄。

| 目錄 | 內容與用途 |
| --- | --- |
| [projects/dream-blueprint/](https://github.com/andy32012/body/tree/main/projects/dream-blueprint) | 完整可編輯專案。在這裡修改、測試、建置與執行 Windows 啟動工具。 |
| [dream/](https://github.com/andy32012/body/tree/main/dream) | GitHub Pages 提供給手機的靜態網站。正式網址為 [xitian.page/dream/](https://xitian.page/dream/)。 |

原始專案包含以下檔案。

- `src/` 有畫面、學習規則及資料版本遷移。`src/data/` 有教材、學校初始資料、赴美路線，以及每張照片的署名與官方來源頁。
- `public/` 保存 56 張實際使用的 WebP、App 圖示、安裝資訊、離線註冊程式與字典授權。需要觀測機構提供的高解析版本時，可依影像清單所列網址前往官方圖庫。
- `scripts/` 有 Windows 預覽工具、離線程式範本與建置後測試。`tests/` 保存學習、排程與資料遷移測試。
- `index.html`、`vite.config.ts`、`tsconfig.json`、`package.json`、`package-lock.json`、`.gitignore`、本說明和 `開啟夢想藍圖.cmd` 隨原始專案一起保存。

## 維護與更新

1. 下載或複製 `body` 專案後，進到 `projects/dream-blueprint/`。Windows 可直接雙擊「開啟夢想藍圖.cmd」。已在本機練習的人，可沿用同一瀏覽器、網址與埠號讀取原有進度。
2. 在上述原始專案目錄開啟終端機。使用 Node.js 24 與 npm，在乾淨副本中逐行執行以下指令。

```powershell
npm.cmd ci
npm.cmd test
npm.cmd run build
npm.cmd run check:offline
```

3. 本機預覽請執行 `npm.cmd run preview -- --host 0.0.0.0 --port 4173`。在手機依前文的步驟測試，包含完成一句、關閉重開，以及還原進度備份。
4. 將建置產生的 `dist/` 內容同步至同一份 `body` 專案根目錄下的 `dream/`，核對網站檔案清單並移除該目錄過時的舊雜湊檔。確認發佈目錄中有 `index.html`、`sw.js`、`manifest.webmanifest`、`assets/` 與 `cosmos/` 的 56 張影像。將原始專案變更及對應的網站檔案放進同一個 Git 提交，檢查差異只出現在 `projects/dream-blueprint/` 與 `dream/`。
5. GitHub Pages 完成發布後，用手機進入本文開頭的正式網址。連網開啟一次，等背景更新後關閉重開。先核對原有累計天數與課表進度，再切飛航模式試練一句。

正式網址下的瀏覽器儲存會跨版本保留，App 開啟時會將舊資料轉成目前格式。修改教材時請維持既有題目、單元與單字 ID。修改資料格式時請補上遷移與匯入測試，保留舊備份可讀性。更新照片時請在同一筆影像資料保留署名與官方頁面，並重新建置影像清單。
