# 夢想藍圖

**手機正式網址**　[開啟夢想藍圖](https://xitian.page/dream/)

玄燁的護理與英文練習手帳。打開「今天」可以看到眼前的一件事，依今天的體力練一句。進度存在使用這個網址的瀏覽器裡。

## 手機第一次使用

1. 用手機常用的 Safari 或 Chrome 開啟上面的正式網址。
2. 在「今天」選電量，按開始，翻譯一個句子並自評。隔天再從同一個瀏覽器或已加入主畫面的 App 開啟。
3. 如果先前已在家中 Wi-Fi 預覽網址練過，從舊網址下載進度備份，再到正式網址的「設定」還原。

## 在電腦上預覽修改，用家裡的 Wi-Fi 試用

1. 在 Windows 電腦上開啟整個「夢想藍圖」資料夾。如果拿到的是 ZIP，先在檔案上按右鍵，選「全部解壓縮」。
2. 雙擊 **開啟夢想藍圖.cmd**。第一次會從網路下載開發工具，等電腦瀏覽器顯示首頁。若電腦尚未安裝 Node.js，下載 LTS 的 Windows Installer 安裝後，再雙擊啟動檔。[Node.js 官方下載](https://nodejs.org/en/download)
3. 讓手機和電腦連上同一個家用 Wi-Fi。把黑色視窗裡「手機網址」那一整串輸入手機瀏覽器。電腦自己開啟時使用 [本機預覽](http://localhost:4173/)。
4. 在手機按「今天」，選電量，開始練一句。完成後，用同一個手機瀏覽器和網址回來查看累計天數。練完可關閉視窗，下次再雙擊啟動檔。

預覽時保持電腦開機，保留啟動視窗。若 Windows 跳出防火牆詢問，請在自己信任的家用「私人網路」允許連線。若手機連不上，確認兩台裝置在同一個 Wi-Fi，請使用視窗裡顯示的 Wi-Fi／乙太網路網址。部分學校、醫院及訪客網路會隔離無線裝置。

## 安裝在手機、帶著離線練

手機透過同一 Wi-Fi 的 HTTP 網址可先練習。要使用離線快取及手機麥克風，請從 HTTPS 網站打開。電腦也可以透過上方的 localhost 網址體驗離線。[瀏覽器安裝條件](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable)

- **iPhone**　用 Safari 打開 HTTPS 網站，點「分享」→「加入主畫面」，有「打開為網頁 App」時將它開啟，再點「加入」。[Apple 操作說明](https://support.apple.com/zh-tw/guide/iphone/iphea86e5236/ios)
- **Android**　用 Chrome 打開 HTTPS 網站，在網址列右側選單點「安裝並建立捷徑」→「安裝」。[Google 操作說明](https://support.google.com/chrome/answer/9658361?co=GENIE.Platform%3DAndroid&hl=zh-Hant)

第一次請連網從主畫面開啟，等頁面及教材載入，重新開啟確認畫面正常，再切飛航模式試一題。朗讀無聲時可選「沒有聲音，改用看的」。錄音權限可略過。

## 今日單字

每天第一次打開首頁會先跳出一張正方形的「今日單字」卡片，依字表順序，每 56 個單字配一輪天文實拍照。翻看中文或播放發音時，照片保持固定。單字來自 7000 單（大考中心高中英文參考詞彙表，六級共 6,012 個詞條），從第 1 級開始。先想意思，再看中文，按「認得」或「還不熟」；還不熟的字隔天進複習。預設每天 20 個，卡片最後或「設定 → 我的學習節奏」可改成 5、8、10、15、20、25 或 30 個。考週和實習期間預設只排 1 個，想多看可以自己加。關掉之後，首頁的「今日單字」按鈕可以再打開。卡片下方的「上一個／下一個」可以往回看今天按過的字（記在 `daily-word.sorted.<日期>`），會直接顯示中文和當時按的是認得還是還不熟，按錯可以改：改成還不熟就變成明天的複習卡，改成認得就把今天新開的卡拿掉，今天看過的個數不變。官方把星期、月份、數字、國名放在字表附錄，不在六級裡，所以今日單字不會出，每日課會教。

### 複習卡怎麼排

規則都在 `src/lib/progress.ts`（`intervals`、`reviewBudget`、`reviewLoad`），今日清單、今日單字和兩個複習畫面都讀同一份，數字不會對不起來。

- **單字卡**在「單字複習」：間隔 1、2、4、8、16、30、60、120、240、365 天，自己想起來才往上一格，想不起來退兩格（365 → 120、240 → 60，前三格回到 1 天）。一天的上限照時間算，五張一分鐘：一般日 100 張（20 分鐘），考週和實習 50 張。超過上限的照到期順序排到明天。
- **句子卡**在「中翻英」：每日課寫過的句子，和從 Emma、短文、課堂存下來的錯句。一句大約一分鐘，一天排 5 句；多的照到期順序排到之後的日子，想多做可以繼續。
- 今日清單的「複習卡」寫出今天要做幾張單字卡、幾句句子卡，兩個按鈕各自帶到單字複習和中翻英；單字複習做完，還有句子卡的話也會提醒去中翻英。
- **新字煞車**：只有超過今天上限、今天複習不完的單字卡會讓新字變少（積 30 張以上開始減，80 張先暫停）。今天清得完的卡、排在後面的句子卡都不會擋新字。
- 複習多的日子，清單上的複習時間最多多 10 分鐘，從加練、今日單字（最少 5 分鐘）、說或寫（最少 15 分鐘）依序挪，一天的總時數不變。
- **7000 單照計畫的速度**（每天打開今日單字、看 20 個新字、先做複習，週日也開）：第 1 級約 2027 年 1 月、第 2 級約 2027 年 3 月（趕在全民英檢初級之前）、第 3 級約 2027 年 7 月、第 4 級約 2027 年 12 月看完（趕在 2028 年 2 月實習和全民英檢中級之前）；實習和國考那段每天只排 1 個新字，第 5 級約 2029 年 6 月、第 6 級約 2029 年 10 月。這是用上面的規則一天一天推算的（第 1 級約四成不認得，越後面越多；改了規則用 `npm run words:pace` 重算，`WORDS=8 npm run words:pace` 可以看別的個數），複習一天平均約 18 分鐘、最多約 28 分鐘；週日沒開會晚 1–7 個月，第 4 級會拖進實習期間（約 2028 年 7 月）。原本預設每天 8 個時，第 4 級要到 2029 年 8 月才看完，比它要對應的全民英檢中級（2028 年初）晚一年半，所以改成 20 個。

## 護理英文（實習和國考期間，平常也能練）

「練習」頁的自選加練有三個護理分頁，教材在 `src/data/nursing-*.json`，規則在 `src/lib/nursing.ts`：

| 分頁 | 內容 | 怎麼練 |
| --- | --- | --- |
| 護理聽力 | 30 段護理師和病人、家屬、醫師的對話（A2 7 段、B1 21 段、B2 2 段；美式、英式、澳洲口音） | 先不看字完整聽一次再答 3 題，答完出現聽力稿、每句中文和重點字；裝置沒有聲音時直接看稿，這次不算「只聽也懂」。順序是沒聽過的先，再來是還沒只聽就全對的。聽完可以按「跟 Emma 演這一段」（`#speaking/nurse-<id>`），她演病人或家屬，你演護理師。 |
| 護理閱讀 | 24 篇衛教單、病房公告、臨床主題短文（A2 8 篇、B1 15 篇、B2 1 篇） | 跟閱讀理解同一套作答、卡在哪和過關規則；紀錄用 `read.n-…`，不和一般閱讀混在一起。 |
| 護理單字 | 240 個字，分身體部位、症狀、生命徵象與評估、檢查與檢驗、器材、給藥、照護動作、醫院人員與地點、疾病、溝通與紀錄 | 看懂（看英文選中文）、聽懂、說出（自評）、寫出，一輪 10 個，答完出例句和中文。 |

實習、國考衝刺和考週的「今天」清單是三格：複習 → 護理英文聽或讀（這週做得少的那個先） → 第三格每天輪流換護理單字題、跟 Emma 演最近聽的那段、護理英文題或臨床情境。累爆的日子只有複習。

## 聽力稿

每一種聽力都有英文稿和每句中文，測試會檢查（`tests/nursing.test.ts`）：每日課和生活主題的對話、單元讀聽說寫與回測、護理聽力在作答後出現全文；句子跟讀有「看聽力稿」，邊播邊看也可以；起點測驗和回測在交卷後，紀錄裡會有那份題本的聽力稿、中文和正確答案（測驗當天自動展開）。新增聽力時每一句都要附中文。

## 7000 單短文

「練習」頁的自選加練裡有「7000 單短文」：六級共 1,476 段日常生活的中文短文，照級別和字母順序排，每一段都是圍繞該字母的單字寫的。先自己翻成英文，再看參考翻譯和這段會用到的單字，最後自評。標成「不會」的會排到後面再出現。六級 1,476 段都有參考翻譯，參考翻譯盡量用到該字母的詞條，下方列出這段會用到的單字。每個單字提示都指到這段英文裡真的出現的字（例如 saw 會標成 see 的過去式「看見」），中文是這一句裡的意思，不是字表最常見的意思；文章沒用到的字不列。寫法不只一種，意思和文法對就算對；想請人細改，可用「複製題目和我的答案」。

## 短文讀聽（閱讀、聽力、聽寫）

「練習」頁的「短文讀聽」把同一批 1,476 段 7000 單短文的英文（六級共約 5.8 萬字）拿來當輸入練習，規則在 `src/lib/story.ts`，畫面在 `src/components/StoryLibrary.tsx`，紀錄存在 `story.<短文 id>`：

| 分頁 | 怎麼練 | 怎麼算 |
| --- | --- | --- |
| 閱讀 | 一句一行，每個字都能點：先給這一段自己的意思（短文的單字提示），沒有就查 7000 單字表，變化形會找回原形（walked → walk、took → take）。每句可以單獨播放。 | 按「讀完了」考最多 3 個沒查過的提示字（這段裡的意思，三選一），再出現整段中文。先看了中文就不考。讀完記一天「讀」。查過的字可以一次加進單字複習。 |
| 聽力 | 先不看字整段播完，自己選聽懂多少（幾乎都懂／大概懂／聽不太懂），再打開文字一句一句跟讀、看中文。 | 整段播到最後才算一天「聽」；裝置沒有聲音或沒回報播完時可以看字，但不算聽力。 |
| 聽寫 | 一次播一句，寫下聽到的，再對答案：寫對幾個字、多寫的字畫波浪線、沒寫到的字列出來。大小寫、標點、縮寫不算錯。 | 寫完兩句以上可以收工；整段的正確字數存起來，算一天「聽」。 |

- **順序**：中翻英從每一級的第一段往後做；讀聽先出已經翻譯過的段落，其他的從最後一段往前，所以還沒翻譯的段落不會先被看到英文。聽寫先出讀過或聽過的段落。
- **今天的清單**：「聽或讀」的「聽」連到短文聽力（原本的句子跟讀還在「練習」頁和寒假的聽力那一格）；「讀」先連到有題目的閱讀理解，A1–B1 那 34 篇（A1、A2 各 15 篇，B1 4 篇）都讀過以後改連短文閱讀（`QUESTION_PASSAGES`，改了篇數測試會提醒）。
- 聲音是裝置的電腦語音，不是真人錄音；速度用設定裡的朗讀速度。
- **有題目的閱讀理解**（`src/data/reading.json`）：A1、A2 各 15 篇（日常、便條、公告、信件、廣告、訊息和衛教），B1 4 篇，B2 是雅思題型。一級裡超過五篇時，要過關八成（15 篇裡 12 篇）才建議往上一級，五篇以下維持三篇（`levelTarget`）；想跳級或留下來多讀，隨時可以自己按程度。

## 文法講解和小練習

每個單元除了原本的一段規則，另外有一份講解（`src/data/grammar.json`，48 個單元都有；規則在 `src/lib/grammar.ts`，畫面在 `src/components/GrammarTeach.tsx`）：

- **三步講解**：每一步一個重點、白話說明和兩個例句（可以點來聽）。
- **一張對照表**：例如主詞配哪個 be 動詞、不規則動詞、三類假設。
- **兩個常見錯誤**：錯的句子、對的句子和原因。
- **七題小練習**：選擇 3 題、填空 2 題、改錯 2 題。填空和改錯用打的，大小寫、標點、縮寫（isn't = is not）不影響；改錯題從錯的句子開始改，沒改不能交。答完出現完整的正確句子和原因。

上課時，「句型」那一步先出講解和小練習，再寫中翻英：單元第 1 天完整講解加前 4 題，第 2 天再 2 題，第 3 天最後 1 題；之前答錯的題目之後每天會先出現，直到答對。小練習不擋住中翻英，也不算進「我會什麼」的證據（那裡只看自己寫出來的句子）；紀錄存在 `gram.<單元>`，只記第一次的對錯，後來改對的另外標記。小關卡（第 6 天）不出講解。

「練習」頁的「文法講解」可以翻任何一個單元的講解、把七題從頭再做一次。新增或修改單元時，`tests/grammar.test.ts` 會檢查每題只有一個標準答案、改錯題的原句不會被判對。

## 發音課（女聲、男聲示範）

「練習」頁的「發音課」有 15 堂短課，每堂 5–8 分鐘，專門教中文母語者最容易念錯、聽錯的地方（內容在 `src/data/pronunciation.json`，規則在 `src/lib/pronunciation.ts`，畫面在 `src/components/Pronunciation.tsx`）：

| 堂 | 內容 |
| --- | --- |
| 1 | KK 音標表：29 個符號各配一個字，點了就聽 |
| 2–6 | 母音對比：sheep／ship、bed／bad、luck／lock、pool／pull、pain／pen |
| 7–10 | 子音：咬舌音 think／sink、l／r／n、v／w、字尾子音 back／bag |
| 11 | -ed 和 -s 的三種念法 |
| 12–13 | 單字重音、句子的輕重（can／can't、13／30） |
| 14–15 | 連音、問句的語調 |

每一堂四步：

1. **怎麼念**：嘴型、舌頭位置，和中文裡最接近的音；一格「容易錯的地方」。
2. **聽聽看**：每個字點一下就播，「比一比」把一組對比字連著念。預設女聲、男聲各念一次（同一個字聽不同的人念，耳朵才認得），也可以只聽其中一個；另外可以切慢速（七成速度，音高不變）。
3. **聽辨小測驗**：只用耳朵選。對比字問「聽到的是哪一個」，字尾問念 [t]、[d] 還是 [ɪd]，重音問在哪一個音節，連音和語調是寫好的題目。選「兩個都聽」時女聲、男聲輪流出題。答對八成算過關，可以重測，紀錄留最好的一次（`pron.<堂>`）。
4. **跟著念**：三個句子，聽完自己念出聲再打勾，可以錄下來跟示範比（錄音只留在畫面上，不會上傳也不會存）。三句都勾了，當天的「說」就算一天。

今天清單的「說或寫」在發音課還沒全部過關之前，會先指到下一堂發音課（不需要任何金鑰）；15 堂都過關後回到 Emma。

**聲音怎麼來的。** 示範不是真人，也不是裝置內建的語音：每個字、每個句子都用開源語音模型 Kokoro-82M（Apache-2.0）預先合成女聲和男聲各一份，放在 `public/pron/`，一堂一個聲音一包（`p01-f.pack`、`p01-m.pack`，共 30 包約 5.5 MB，全部約 8 分鐘的聲音）。女聲主要是 af_bella、男聲主要是 am_adam，個別的字換成同性別的另一個聲音。合成時給的是音標而不是拼字，重音和母音照音標念；每一段錄好後再用語音辨識檢查：單字要在「只差一個音的字」和它的對比字裡明顯勝出，句子要一字不差地被聽回來，而且是壓成 mp3 之後、量三次都過才算；沒過的換速度或換同性別的另一個聲音重錄。對比字一開始準備得比課程裡多，女聲、男聲都念得清楚的才留下（例如男聲的 seat 聽起來像 seed，所以 seat／sit 沒有放進課程；cup／cop 女聲分不清楚，換成 luck／lock）。打包好的成品再整個檢查一次。製作工具和每一段的檢查紀錄在 `scripts/pronunciation/`。

語調那一堂另外處理：這個語音模型幾乎每一句的句尾都往下掉，連 yes／no 問句也一樣。該下降的句子用原本合成的版本；該上升的句子，句尾的音高是後製拉上去的（重新合成），做完再量一次音高確認方向。

發音包不跟著 App 一起下載：打開一堂課時才抓那一堂的兩包，抓過的會留在裝置裡（離線可播，App 更新也不會清掉）；課程清單最下面可以一次全部存好。抓不到的時候（第一次打開又剛好沒網路）會改用裝置的語音念，畫面上會寫明。

發音課能教的是「聽得出差別」和「知道怎麼念」。App 聽不到你的聲音，不會評你的發音；要有人聽你念，還是要找老師或同學。

## 宇宙圖鑑與背景

「宇宙圖鑑」收錄 56 張天文觀測影像，分為星雲 12 張、星系 12 張、太陽系 12 張、恆星與星團 10 張，以及深空 10 張。點分類，再點影像即可放大。每次切換主要頁面或重新開啟 App，滿版背景就接續輪替。在自動輪替下，56 張全看過後才重複。頁首搭配另一張實拍照，閱讀、答題和切換同頁設定時，照片保持固定。想固定某頁的全頁背景時，在大圖底下的「頁面背景」選頁面，按「設為這張」。按「自動輪替」能恢復該頁輪替。

每張照片的出處、署名與授權記錄保存在影像資料檔，建置時一併輸出為[影像出版資訊](https://xitian.page/dream/publication.html)。App 的 HTML 文件標頭透過 `rel="license"` 指向這份清單。照片來自 NASA、ESA/Hubble 與 ESA/Webb 的官方圖庫。引用或轉載時，請保留該張完整署名，並查看原始頁面的使用條款。[NASA 科學影像](https://science.nasa.gov/) · [ESA/Hubble 影像庫](https://esahubble.org/images/) · [ESA/Webb 影像庫](https://esawebb.org/images/)

如果要在沒有網路的地方瀏覽全部照片，請先用正式網址打開「宇宙圖鑑」，按「保存全圖庫供離線瀏覽」，等到顯示「全庫可離線瀏覽」。56 張 WebP 合計約 8.3 MB。下載中斷時可連線再按一次，已保存的影像會保留。新手機還原進度後，請在新手機上重新保存圖庫。

## 把進度帶到其他裝置

1. 在原裝置開「設定」→「備份與還原」→「下載備份」，保留下載的 JSON 檔。換網址、換瀏覽器或清除網站資料前，也先做一次。
2. 在新裝置開「設定」→「備份與還原」→「選擇備份檔」，選取 JSON 後按「確認還原」。匯入會取代目前的進度，有想保留的資料時可先下載備份。
3. 到「紀錄」核對累計天數，再回首頁看英文單元位置。

資料儲存在目前裝置。手機與電腦各有自己的進度；從預覽網址換到正式網址時，用備份把進度帶過去。

也可以在「設定」→「雲端硬碟」接上自己的 Google Apps Script，讓進度和記住的事同步到自己的試算表：

- 每台裝置記得自己上次同步時雲端那一份的時間。雲端比這個時間新、這台也改過，就是**衝突**：不會自動互蓋，設定頁會讓你選留這台還是留雲端那份。
- 新版腳本（設定頁的程式碼，v2）在伺服器端也會檢查這個時間，兩台同時存檔時只有一台成功。還沒換新版腳本時，網頁這邊會先檢查一次，但同時按存檔的極短時間內仍可能互蓋，所以請照設定頁的步驟更新並重新部署。
- 刪掉的記憶會記在「已刪除的記憶」，別台的舊資料合併回來時不會復活。
- 對話逐字稿寫進試算表預設是**關閉**的，要在設定頁自己打開。

## 教材與個人資料

英文課表以玄燁提供的 42 單元順序為準，後面再接 6 個 B1→B2 橋接單元（43–48），共 48 個單元，每個都有完整的每日教材：每單元 5 天各一句中翻英、第 6 天三句小關卡，另有 5 句沒過關時用的備用句。考週、實習與休息都能暫停；每天以裝置當地凌晨 4 點換日。

### 英文程度階梯（A1 → C2）

課程照 CEFR 分級往上排，每一級最後考一張證照，考過才算升級（`src/lib/cefr.ts`，畫面在「夢想星圖 → 英文程度」）：

| 這一段 | 每日課 | 7000 單 | 結業證照 | 預估 |
| --- | --- | --- | --- | --- |
| A1 → A2 | 單元 1–16 | 第 1–2 級（照計畫約 2027/3 看完） | 全民英檢初級（聽讀＋說寫） | 2027 年中 |
| A2 → B1 | 單元 17–30 | 第 3–4 級（第 3 級約 2027/7、第 4 級約 2027/12，實習之前） | 全民英檢中級 | 2028 年初 |
| B1 → B2 | 單元 31–42，再接橋接單元 43–48 | 第 5–6 級（約 2029/10） | 全民英檢中高級，或雅思學術組 5.5 以上 | 2030 年中 |
| B2 → C1 | 還在寫，先用雅思閱讀、寫作、口說練 | 學術字彙 | 雅思 7.0（或全民英檢高級） | 2031 年底 |
| C1 → C2 | 選修，不排進五年計畫 | | 雅思 8.5 或劍橋 C2 | 到美國以後 |

- **關卡怎麼擋**：下一段的每日課，要等前一段的證照考過、或至少報名了（填上考試日期）才開。等成績的時候可以先讀；成績沒過，就要再報名下一場才會接著上。日曆也照這個規則排，還沒報名就停在下一段的第一天。
- **全民英檢**要聽讀和說寫兩個都過，可以分開考（及格線：聽讀合計 160、單項不低於 72；說寫初級寫作 70、口說 80，中級以上都 80）。直接考過更高一級也算（沒考初級、直接考過中級就是 B1）。也可以填其他證照和它的 CEFR 等級。
- **美國 RN 的 VisaScreen** 要雅思學術組總分 6.5、口說 7（2026-05-12 之後考的）。填了雅思成績，達到就會顯示，並提醒成績一般兩年內要送件。VisaScreen 不收全民英檢，所以 C1 那關要考雅思。
- 費用、場次和及格線是 2026 年 11 月查的，寫在 `cefr.ts` 的 `exams`；改了就改那裡。
- **Emma 的程度跟著每日課走**：A1→A2 那段她講很簡單、很慢的 A1–A2；A2→B1 是 A2–B1；B1→B2 換成正常語速、一次兩三句，會追問 why／how；B2→C1 再加上抽象話題，要他說理由、比較和推測（`cefr.ts` 的 `emmaLevel`）。

### B1→B2 橋接單元（43–48）

接在單元 42 後面、考中高級之前，補 B2 常用但前面沒教的句型：敘事時態（過去進行、過去完成、used to）、未來進行和未來完成、推測（must／might／can't have）、第三類假設、wish 和 should have、加逗號的非限定關係子句。每個單元照樣一週六天，第 6 天是小關卡，沒過一樣用備用句再練，不拆成兩週。

每個橋接單元另外有一包讀聽說寫（`src/data/bridge.json`，畫面在「英文練習 → 單元讀聽說寫」）：

| 一包裡有什麼 | 怎麼做 |
| --- | --- |
| 詞塊 15–20 個 | 先聽例句跟著念；可以遮住英文，看中文先說再對答案。 |
| 閱讀兩篇（B2，約 250–320 字） | 用閱讀理解原本的作答方式；文章就用這一課的文法寫。 |
| 聽力一段 | 電腦語音，盡量用英式或澳洲口音（看裝置有沒有那種語音，沒有就用其他英文語音，畫面上會寫）。先不看字聽完才開題目，播放沒確認聽完的不算「只聽也懂」。這不是真人錄音。 |
| 寫作兩題（約 100、120 字） | 放在寫作階梯的「⑥ 橋接段落」；第一個評分項目是有沒有用到、用對這一課的文法。這一階不會變成寫作階梯的建議，從單元進去寫。 |
| 口說兩個任務 | 跟 Emma 練（`#speaking/pack-單元-題號`），她會照任務演情境、追問，句型錯了請他再說一次。 |
| 回測 | 一篇沒看過的閱讀和一段沒聽過的聽力（換一種口音），第 6 天或上完單元才開，各只有一次機會、只記第一次。回測的文章不會出現在閱讀理解裡。成績會和練習文章並排，看學的東西能不能用在新的材料上。 |

今天的清單也會用到：「聽或讀」「說或寫」會看這週聽、讀、說、寫各做了幾天，指向做得少的那一個（一樣多時先聽、先說）；目前的單元有讀聽說寫包時直接連進去，第 6 天的「聽或讀」換成回測。

### 每天多久

每天多久由 `src/lib/dailyPlan.ts` 一處決定，首頁的三個選項、今天的清單、待辦那一行和計畫日曆都讀它，所以分鐘數不會各說各話：

| 哪一天 | 預設 | 其他選項 |
| --- | --- | --- |
| 學期中週一到週六（設定裡的上課日） | 1.5 小時：複習 15、一堂 25、單字 10、聽或讀 20、說或寫 20（卡片多的日子複習最多 25，單字和說或寫各讓 5 分鐘） | 有電 2 小時（加練 30）；累爆 15 分鐘（複習＋單字） |
| 寒假週一到週六 | 3 小時：複習 20、一堂 25、單字 20、聽力跟讀 25、閱讀 25、寫作 25、口說 20、證照準備 20 | 有電 4 小時（加練 60）；累爆 30 分鐘 |

| 週日、過年、沒排課的日子 | 15 分鐘複習，標「選做」 | 想上課也可以選 |
| 段考週 | 15 分鐘複習或休息，標「選做」 | 30 分鐘護理英文 |
| 實習（2028-02 起） | 20–30 分鐘護理英文：複習、聽或讀一段護理英文，再輪流練護理單字／跟 Emma 演一段／護理題 | 忙的日子 10 分鐘 |
| 國考衝刺（考試期間連續四週以上） | 15 分鐘護理英文 | 忙的日子 5 分鐘 |

### 今天的清單怎麼打勾

- **複習卡**：今天沒有到期的卡就直接算完成（第一天會寫「還沒有複習卡，先跳過」），旁邊的按鈕改成選做的單字快篩。
- **今天這一堂**：引導課要做到最後一步「表達」才打勾；單元小關卡（第 6 天）做完也算，而且同一天不會再排生活主題（`mainLessonDone`、`courseMovedOn`）。
- **聽或讀**：要真的去聽或讀才算（短文讀聽、閱讀理解、練習頁的句子跟讀、單元聽力）。課堂裡跟讀的那一句屬於那堂課，不算。
- **說或寫**：發音課的三個句子跟著念完、跟 Emma 說過話，或在寫作階梯存了一題。
- **先補強**：做了它要求的練習就會自己勾（聽懂練習當天答對 5 個字，或在練習頁多寫 2 句）。
- 每一項左邊的方框都可以自己勾或取消。

首頁在第一次練習之前會有一張「第一次用？照這三步就好」的說明卡，上完第一堂課或按「知道了」就不再出現。

寒假文法課還是一天一堂：關卡是證照，不是單元數，上太快只會記不住，多出來的時間全部拿去聽讀說寫和準備下一張證照。清單裡每一項的分鐘加起來就是選項上寫的分鐘；今天有「先補強」時，從複習時間裡撥出來。舊的預設（週二、四、六各 30 分鐘）會自動換成週一到週六；自己改過的上課日不動。

2028 年 2 月至 2029 年 7 月是實習和國考，暫停新單元與 7000 單新字，只做護理英文（見下方「護理英文」）。假期有排實習時用實習模式，只有沒有實習的假期才啟用寒暑假模式。

學籍與待修科目取自 2026-11-13 提供的資料。每週正式上課節次、部分計畫明細在附件中留白，可在設定更新。基護已確認安排在暑假，年份與日期尚未指定。畢業年月以校方確認為準。2033–2034 年是玄燁期望抵美的時間，實際日期取決於畢業、考試與當時的移民排期。跨國執照、簽證等規定請用地圖列出的官方連結再次查閱。

## 生活主題

生活主題放在 `src/data/topics.json`，接在每日主線裡，和文法課輪流上（上一個練習日是生活主題，下一個就是文法課；同一天只排一堂）。前四個（認識新同學、一天的作息、房間與住處、點餐與買食物）在上完單元 1、5、6、7 後依序開放；後面五個補 48 個單元沒有獨立教到的文法，一樣照順序開放：

| 主題 | 上完單元幾開放 | 補的文法 |
| --- | --- | --- |
| 5 這是誰的？ | 8 | me／my／mine／myself（受格、所有格、所有格代名詞、反身代名詞，by myself） |
| 6 照著說明做 | 15 | 形容詞和副詞（slow／slowly、good／well、hard／hardly；look、feel 接形容詞） |
| 7 這也太好吃了吧！ | 17 | so 和 such、so／such … that …（和單元 17 的 so「所以」對照） |
| 8 確認一下，對吧？ | 20 | 附加問句（…, isn't it?／…, do you?，助動詞跟著前面的時態，語調和回答） |
| 9 請人幫你處理 | 21 | 使役句 have／get something done（接在單元 21 被動語態的過去分詞後面） |

主題的 id 接著編（t5–t9），既有單元、題目和單字的 id 都沒有動，學過的進度不受影響。每個主題分三次：

1. 理解：單字在句子裡選意思 → 句型中翻英 → 聽（只聽大意 → 再聽細節 → 看逐字稿 → 跟讀 → 重述）→ 讀（主旨、細節、指涉、文章有沒有提供）。只聽、不看字時的答案先存起來，重聽次數和看逐字稿另外記。
2. 說和寫：只給情境和要做到的條件。口說可以錄音（只留在畫面上），把說的話打下來或轉成文字再請 Claude 看；只看文字稿，所以發音一律記「未評估」，並給一到兩個下次的目標。訊息寫 3–5 句。
3. 換情境：第 2 次之後至少隔 3 天，三句新句子加一個新的口說情境。有兩句以上自己寫、而且確認過，才記成「延後換題仍能完成」。

判定和其他地方一樣：沒寫是未作答；看過提示或參考是有提示完成；沒人確認的自評是自評完成・待確認；Claude 第一次就說對、或跟參考答案一樣，才是當次獨立完成。句子會進複習卡，字典裡有的新單字會進單字卡。想先上文法課，按「今天先上文法課」就好，生活主題下次接著做。

聽力只算**整段播完**的那次；裝置沒回報播放結束時可以按「播完了，但題目沒有打開？」先作答，但那次不算「只聽就懂」。口說分成「錄了音」「說了但沒錄」「用打的」三種，用打的不算口說。寫作訊息要 3–5 句（兩個字以上才算一句）。計畫日曆用同一套規則排出生活主題的日子。

## 維護與更新

1. 下載或複製 `body` 專案後，進到 `projects/dream-blueprint/`。Windows 可直接雙擊「開啟夢想藍圖.cmd」。已在本機練習的人，可沿用同一瀏覽器、網址與埠號讀取原有進度。
2. 在上述原始專案目錄開啟終端機。使用 Node.js 24 與 npm，在乾淨副本中逐行執行以下指令。

```powershell
npm.cmd ci
npm.cmd test
npm.cmd run build
npm.cmd run check:offline
```

3. 本機預覽請執行 `npm.cmd run preview -- --host 0.0.0.0 --port 4173`。在手機依前文的步驟測試，包含完成一句、關閉重開，以及還原進度備份。
4. 將建置產生的 `dist/` 內容同步至同一份 `body` 專案根目錄下的 `dream/`，核對網站檔案清單並移除該目錄過時的舊雜湊檔。確認發佈目錄中有 `index.html`、`sw.js`、`manifest.webmanifest`、`assets/` 與 `cosmos/` 的 56 張影像。將原始專案變更及對應的網站檔案放進同一個 Git 提交，檢查差異只出現在 `projects/dream-blueprint/` 與 `dream/`。
5. GitHub Pages 完成發布後，用手機進入本文開頭的正式網址。連網開啟一次，等背景更新後關閉重開。先核對原有累計天數與課表進度，再切飛航模式試練一句。

正式網址下的瀏覽器儲存會跨版本保留，App 開啟時會將舊資料轉成目前格式。修改教材時請維持既有題目、單元與單字 ID。改了已上線教材的意思或答案時，把改到的單字和句子 ID 加進 `src/data/content-updates.json`：使用者學過的那幾張卡會排進當天複習，進度不歸零，首頁會出現一次「教材修正了」。

字表（`levels.json`）的 `zh` 用「；」分開不同意思，`sensePos` 依序標出每個意思的詞性；合併詞條（he (him, his, himself)、agree(ment)）的 `forms` 列出每個字形自己的意思，拼字練習一次只問一個字形。短文的單字提示（`passages.json` 的 `words`）是照每一段的句子寫的，`form` 是文章裡的字、`zh` 是那一句的意思；修改字表時不要拿字表的中文覆蓋短文提示。

作答判定在每個入口都一樣：沒寫答案不算作答；看過提示或答案是「有提示完成」；自己按「對了」但沒有可核對的答案是「自評完成・待確認」；答案和參考答案一致或 Claude 第一次批改就判對，才是「當次獨立完成」；之後換一句還能獨立寫對，才會變成「穩了」。

幾個細節：Claude 的「對了」只算它看過的那一版，看完再改句子就要重新確認（只差標點不算改）；第一次被指出錯、改完才對，是有提示完成；學生寫的縮寫（He's、I'd）兩種讀法都會試，參考句的縮寫照後面的字決定是 is／has、would／had；重音字母（café）不算錯。自評的「對了」不會讓複習卡升級，只是先停在原地，確認過才往上升。單字「說出」目前沒有錄音核對，記成「說出（自評）」；「聽懂」要等聲音真的播出來才能選。寫作批改回來的項目名稱要對得上評分項目、雅思 band 要跟四項平均差不多，不然整筆不算；Task 2 依題型（討論兩方、問題＋解決、同意程度）給不同的結構提示。閱讀同一天重做是練習，不會蓋掉第一次的成績。修改資料格式時請補上遷移與匯入測試，保留舊備份可讀性。更新照片時請在同一筆影像資料保留署名與官方頁面，並重新建置影像清單。
