#L p01 | pairs | 長短音：sheep 和 ship | [i] / [ɪ]
H [i] 是長音：嘴角往兩邊拉，像微笑，聲音拉長。sheep、eat、sleep 都是這個音。
H [ɪ] 是短音：嘴巴放鬆、稍微開一點，短短帶過，聽起來介於「一」和「ㄝ」之間。ship、it、slip 都是這個音。
T 中文只有一個「一」，所以 ship 很容易念成 sheep。念 [ɪ] 的時候不要微笑，嘴巴放鬆就對了。
P6 sheep / ship ; eat / it ; seat / sit ; sleep / slip ; feel / fill ; heat / hit ; leave / live ; feet / fit ; cheap / chip ; beat / bit ; reach / rich ; seek / sick ; wheel / will ; steal / still ; meal / mill ; green / grin
S I need to sleep a little bit. = 我需要睡一下。
S I feel a little ill. = 我覺得有點不舒服。
S He will leave, but I live here. = 他會離開，但我住在這裡。

#L p02 | pairs | 嘴巴開多大：bed 和 bad | [ɛ] / [æ]
H [ɛ]：嘴巴半開，像中文的「ㄝ」，短短的。bed、pen、said 都是這個音。
H [æ]：嘴巴張大、嘴角往兩邊拉，下巴往下掉，像要咬一大口蘋果，聲音比較長。bad、pan、sad 都是這個音。
T 中文沒有 [æ]，常常念得跟 [ɛ] 一樣。念 [æ] 時下巴要比你習慣的再往下一點。
P6 bed / bad ; men / man ; pen / pan ; said / sad ; head / had ; guess / gas ; bet / bat ; set / sat ; send / sand ; pet / pat ; met / mat ; ten / tan ; dead / dad ; beg / bag ; lend / land
S The man said he was sad. = 那個男人說他很難過。
S I had a headache in bed. = 我躺在床上的時候頭痛。
S My pen is in the pan. = 我的筆在鍋子裡。

#L p03 | pairs | luck 和 lock | [ʌ] / [ɑ]
H [ʌ]：嘴巴開一點點、放鬆，短短的，介於「ㄚ」和「ㄜ」之間。luck、cup、color 和 stomach 的 o 都是這個音。
H [ɑ]：嘴巴張大，像看醫生時說「啊」，聲音拉長。美式英文的 lock、hot、doctor、not 都是這個音，不是「ㄛ」。
T 台灣常把 hot、doctor 的 o 念成「ㄛ」。美式發音是張大嘴的「啊」。
P6 cup / cop ; luck / lock ; hut / hot ; nut / not ; duck / dock ; color / collar ; shut / shot ; cut / cot ; rub / rob ; stuck / stock ; come / calm ; buddy / body ; suck / sock ; hug / hog ; gut / got ; dull / doll ; wonder / wander ; gulf / golf ; rubber / robber ; bucks / box ; fund / fond ; pup / pop ; sub / sob
S The doctor is not at lunch. = 醫師不在吃午餐。
S Lock the door, and good luck. = 把門鎖上，祝你好運。
S My stomach hurts a lot. = 我的胃很痛。

#L p04 | pairs | pool 和 pull | [u] / [ʊ]
H [u] 是長音：嘴唇圓圓往前嘟，聲音拉長。pool、food、blue 都是這個音。
H [ʊ] 是短音：嘴唇放鬆、只有一點點圓，短短帶過，有點像「ㄜ」加一點「ㄨ」。pull、good、book、foot 都是這個音。
T 中文只有一個「ㄨ」，所以 pull 常被念成 pool。念 [ʊ] 時嘴唇不要嘟出去。

#L p05 | pairs | pain 和 pen | [e] / [ɛ]
H [e] 是會滑動的音：從「ㄝ」滑到「一」，嘴巴會動，聲音比較長。pain、late、wait 都是這個音。
H [ɛ]：嘴巴不動，短短的「ㄝ」。pen、let、wet 都是這個音。
T 護理最常說的 pain（痛）不要念成 pen（筆）。念 pain 時要聽得到後面那個小小的「一」。
P6 pain / pen ; late / let ; wait / wet ; taste / test ; paper / pepper ; main / men ; gate / get ; date / debt ; sale / sell ; tale / tell ; fail / fell ; age / edge ; whale / well ; raid / red
S Where is the pain? = 哪裡痛？
S Wait, the floor is wet. = 等一下，地板是濕的。
S Take the test later. = 晚一點再做檢查。

#L p06 | pairs | 咬舌音：think 和 sink | [θ] [ð] / [s] [t] [d] [z]
H [θ] 和 [ð]：舌尖輕輕放在上下牙齒中間（照鏡子看得到舌尖），把氣吹出去。
H [θ] 喉嚨不震動：think、three、mouth、breath。[ð] 喉嚨要震動：this、they、breathe。
T 中文沒有咬舌音，常被念成 s、t 或 d：think 變 sink、three 變 tree、they 變 day。舌尖一定要伸到牙齒中間。
P7 think / sink ; thank / sank ; mouth / mouse ; three / tree ; they / day ; then / den ; breathe / breeze ; thick / sick ; thing / sing ; path / pass ; thin / sin ; worth / worse ; those / doze ; there / dare ; thumb / sum ; faith / face ; thank / tank ; thin / tin

S Breathe in through your mouth. = 用嘴巴吸氣。
S Thank you for these three things. = 謝謝你給我這三樣東西。

#L p07 | pairs | light 和 right、night 和 light | [l] / [r] / [n]
H [l]：舌尖頂住上排牙齒後面的牙齦，氣從舌頭兩邊出去。
H [r]：舌頭往後捲，不碰到任何地方，嘴唇稍微圓。
H [n]：舌尖也頂住牙齦，但是氣從鼻子出來。捏住鼻子就發不出 [n]，可以用這個方法檢查。
T l 和 r、n 和 l 是最常被聽錯的音。念 right 時先把嘴唇嘟圓，舌頭不要碰上面。

#L p08 | pairs | very 不是 wery | [v] / [w] / [b] / [f]
H [v]：上排牙齒輕輕咬住下嘴唇，喉嚨震動。它就是 [f] 加上聲音。
H [w]：嘴唇圓圓嘟起來，牙齒不碰嘴唇。[b]：兩片嘴唇閉起來再彈開。
T 中文沒有 [v]，very 常被念成 wery，或把 v 念成 b。牙齒要碰到下嘴唇才是 [v]。

#L p09 | pairs | 字尾不要吞掉：back 和 bag | 字尾子音
H 中文的字尾幾乎沒有子音，所以很容易把英文字尾吞掉：card 念成 car、white 念成 why。字尾的 p、t、k、b、d、g 要做出嘴型，輕輕帶出來。
H 字尾有聲（b、d、g、z、v）時，前面的母音會拉長：bag 的 a 比 back 的 a 長，rise 的 i 比 rice 的 i 長。
T 聽不出 back 和 bag 的差別時，先聽母音的長短，再聽字尾。

S Put the bag on your back. = 把袋子背在背上。

#L p10 | endings | -ed 和 -s 的三種念法 | [t] [d] [ɪd]、[s] [z] [ɪz]
H -ed：前面是無聲的音（p、k、f、s、sh、ch）念 [t]；前面是有聲的音（母音、b、g、l、m、n、v、z）念 [d]；前面是 t 或 d 時多一個音節，念 [ɪd]。

T 最常見的錯：把 walked 念成兩個音節（walk-id）。只有 t、d 後面才多一個音節。

#L p11 | stress | 單字重音：HOSpital | 重音
H 兩個音節以上的英文字，都有一個音節特別大聲、特別長、音調也比較高，其他音節變輕變短（常常變成 [ə]）。
H 重音放錯，母語人士常常聽不懂，比母音念不準還嚴重。查字典時，重音符號 ˋ 或 ˈ 後面那個音節就是重音。

#L p12 | pairs | 句子的輕重：can 和 can't、15 和 50 | 句子重音
H 句子裡重要的字（名詞、動詞、形容詞、否定）念得大聲又清楚；小字（a、the、to、of、and、can、代名詞）念得又輕又快。
H can 平常念得很輕，像 [kən]；can't 一定重讀 [kænt]，字尾的 t 常常聽不到。所以分辨 can 和 can't 要聽輕重，不是聽 t。
H 數字也靠重音：thirTEEN 重音在後面，THIRty 重音在前面。給藥劑量聽錯很危險，不確定就再問一次。
T 自己說的時候，can't 要念重、念清楚；說十幾時把 -teen 拉長。
P2 I can swim. / I can't swim. ; She can walk. / She can't walk. ; He can come. / He can't come. ; We can go. / We can't go.
P4 thirteen / thirty ; fourteen / forty ; fifteen / fifty ; sixteen / sixty ; seventeen / seventy ; eighteen / eighty ; nineteen / ninety
S I want to go home. = 我想回家。
S A cup of tea, please. = 請給我一杯茶。
S Take it twice a day. = 一天吃兩次。
