# 分級寫作：B1 以後的規劃（還沒出題）

A1、A1+、A2、A2+ 四級已經在 `src/data/writing.json`（各 20 題）。這份是之後各級的題型和出題原則，題目還沒寫。原本的「一段、多段、雅思 Task 1／2」27 題先照用，等下面各級補齊後再依難度併進來。

## 共同原則

- 每題標 `after`（學完第幾單元才開放），不要求還沒教的文法；題目以日常生活為主（為了雅思），護理情境少量。
- 批改照分層提示：第一次只說錯的類型和位置，第二次清楚一點，第三次才給答案；沒教過的直接用中文教一句再給例子；文法和意思對就算過。
- 每級至少 20 題，題型輪流出現；範文只在 Claude 連不上、自己寫過一次後才看得到。

## B1（約 100–150 字，學完單元 36–47）

- 題型：說明理由的短文（一個立場、兩個理由、各一個例子）、比較兩個選擇、經驗敘述（背景＋經過＋結果，過去完成式）、正式 email（請假、詢問、抱怨）。
- 結構：主題句 → 2–3 個支持句（each with an example）→ 結論句；段落內用 First／Also／However／As a result。
- 評分項目：回答題目所有部分、段落結構、連接詞和指代（this、they）、時態與文法、用字。

## B1+（約 150–200 字，兩段，學完單元 44–53）

- 題型：兩段式意見文（自己的看法＋另一方的看法）、圖表的簡單描述（3–4 句趨勢，Task 1 入門）、問題＋解決方法、給建議的信。
- 開始練「先寫大綱再寫」：每題先填三行大綱（立場、理由一、理由二）。

## B2（雅思 Task 1／Task 2 正式題型）

- Task 1（150 字以上，20 分鐘）：折線、長條、表格、圓餅、流程、地圖輪流；必須有 overview，挑重點比較，不逐一列數字。
- Task 2（250 字以上，40 分鐘）：discuss both views、problem／solution、advantages／disadvantages、to what extent 四種輪流；立場清楚，每段一個重點。
- 每題寫完隔天依回饋重寫一次；評分用雅思四項，分數只是練習估計，要定期找真人或正式模考校準。

## C1（IELTS 7 目標）

- 同樣的 Task 1／2，但限時、追求用字精準、句型變化和論點深度；每兩週一份完整模考。
- 另外加學術摘要（讀一篇短文寫 100 字摘要）和改寫練習（同一段用不同句型重寫）。
