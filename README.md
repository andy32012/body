# Body

學習入口首頁：漫畫、內外科護理，以及日文、英文、韓文。

- `index.html` / `style.css`：iOS 風格方塊拼貼首頁
- `nursing/`：內外科護理（目前有「心衰竭：左 vs 右」）
- `japanese/`、`english/`、`korean/`：語言課（準備中）

漫畫在 `comic/`，來自 andy32012/xitian 的副本（原 repo 未改），頁面：[西天｜線上漫畫](comic/)。

每堂課的語音事先生成好放在 `audio/` 資料夾，網頁播放時不需要連線到任何 API，也沒有存放任何金鑰。

筆順資料來自 [Make Me a Hanzi](https://github.com/skishore/makemeahanzi)（Arphic Public License），英文字使用 Hershey 字型。
